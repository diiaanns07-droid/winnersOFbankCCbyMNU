**Суть:** Метод GET для изменяющей операции «/alerts/saveLimit»

**Критерий:** Корректность (29148 5.2.5; 830 4.3.1) · **Статус:** подтверждено · **Требования:** [R-012](#r-r-012), [R-014](#r-r-014)

Место: Часть B. REST API › Общие параметры, страница 4 · цитата сверена с текстом документа

Место: Часть B. REST API › Общие параметры, страница 4 · цитата сверена с текстом документа

**Последствия:** GET по RFC 9110 — безопасный метод: прокси, кэши, предзагрузка и повторы могут выполнить изменение повторно или без ведома клиента; параметры уходят в строку запроса и оседают в логах веб-серверов и прокси (риск ИБ для идентификаторов и персональных данных).

**Что сделать:** Заменить GET на POST (или PUT/PATCH для идемпотентной замены), параметры передавать в теле запроса; для чтения выделить отдельный GET-метод. \<уточнить: итоговый метод и URL для /alerts/saveLimit\>.
