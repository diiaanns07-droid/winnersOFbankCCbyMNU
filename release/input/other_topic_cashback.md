# Кэшбэк за покупки в выбранных категориях

Учебный документ команды для проверки агента на другой тематике. Дефекты засеяны намеренно.

## Часть A. Бизнес-требования

### Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Кэшбэк в выбранных категориях |
| **Продукт** | Мобильный банк |
| **Задача в JIRA** | CB-101 |

### Цели
Повысить вовлечённость клиентов: клиент быстро видит начисленный кэшбэк и выбирает выгодные категории.

### Функциональные требования
* **КБ-1.** Клиент с активной дебетовой картой выбирает до 3 категорий кэшбэка на календарный месяц. Выбор доступен с 1 по 5 число месяца.
* **КБ-2.** За покупку в выбранной категории начисляется 5 % от суммы покупки, но не более 10 000 ₸ в месяц на клиента.
* **КБ-3.** Кэшбэк начисляется в течение 2 рабочих дней после проведения покупки.
* **КБ-4.** Клиент может изменить выбранные категории в любой момент месяца.
* **КБ-5.** Кэшбэк за возвращённую покупку списывается и т. д.

### Нефункциональные требования
Экран кэшбэка открывается быстро и удобно для клиента.

### Требования к данным
Хранить идентификатор клиента, месяц, выбранные категории, сумму кэшбэка в тиынах и лимит в тенге.

### Требования к интеграции
Приложение получает и меняет выбранные категории через документ «Кэшбэк — REST API».

### Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Выбрана категория «Кафе», кэшбэк за месяц 0 ₸ | Покупка в кафе на 20 000 ₸ | Начислено 1 000 ₸ |
| 10 число месяца, выбраны 3 категории | Клиент меняет категорию «Кафе» на «Такси» | Категория изменена |
| Кэшбэк за месяц 9 800 ₸ | Покупка в выбранной категории на 10 000 ₸ | Начислено 500 ₸ |

## Часть B. REST API

Дочерний документ части A: «Кэшбэк — REST API».

### Общие параметры

| Поле | Значение |
| :--- | :--- |
| **Description** | Сохранение выбранных категорий |
| **REST type** | GET |
| **Request URL** | `/cashback/setCategories` |

### Параметры запроса

| Parameter | Format | Mandatory | Description |
| :--- | :--- | :--- | :--- |
| `clientId` | string | Да | Идентификатор клиента |
| `categories` | array | Да | Коды категорий, не более 3 |

### Ответ

| Parameter | Format | Description |
| :--- | :--- | :--- |
| `categories` | string | Сохранённые категории |
| `status` | string | OK / ERROR |

### Статусы

**200.** Успешное сохранение.  
**400.** Неверные параметры.

#### 200. OK
```json
{"status":"ERROR","message":"Нельзя выбрать больше 3 категорий"}
```
