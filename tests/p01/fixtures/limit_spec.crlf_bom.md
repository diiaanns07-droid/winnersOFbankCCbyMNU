# Лимит переводов

## Правила

1. Лимит переводов в сутки[^1]

   | Канал | Лимит | Подтверждение |
   | :--- | :--- | :--- |
   | Мобильное приложение | 50 000 ₸ | не требуется |
   | Интернет-банк | 50 000 ₸ | код из SMS |

2. Перевод сверх лимита отклоняется.

Перевод свыше 50 000 ₸ требует звонка в банк, лимит 50 000 ₸ при этом не меняется.

[^1]: Сутки считаются по времени Астаны, лимит 50 000 ₸ общий для всех каналов.
