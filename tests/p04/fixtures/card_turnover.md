# Учёт оборота по картам

Документ задаёт правила включения операций в оборот месяца.

## 1. Дебетовые карты

К-1. Операция включается в оборот месяца по дате её проведения.

Исключение: возвраты в оборот не включаются.

## 2. Корпоративные карты

К-1. Операция включается в оборот месяца по дате её проведения.

## 3. Схема

Процессинг → учёт оборота → отчёт клиенту.
