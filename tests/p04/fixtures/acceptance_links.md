# Карты: блокировка и уведомления

## 1. Дебетовая карта

ДК-1. После трёх неверных вводов PIN-кода подряд дебетовая карта блокируется на 24 часа.

ДК-2. О каждой операции по дебетовой карте на сумму от 50 000 ₸ клиенту отправляется SMS.

## 2. Кредитная карта

КК-1. После трёх неверных вводов PIN-кода подряд кредитная карта блокируется до обращения в банк.

КК-2. Выписка по кредитной карте формируется 1-го числа каждого месяца.

## 3. Критерии приемки

| № | Проверка | Ожидаемый результат |
| --- | --- | --- |
| АК-1 | ДК-2: оплата дебетовой картой на 50 000 ₸ | Клиенту отправлено SMS об операции |
| АК-2 | Наступило 1-е число месяца | Выписка по кредитной карте сформирована |
| АК-3 | Третий подряд неверный ввод PIN-кода | Карта заблокирована |
| АК-4 | ДК-3: снятие наличных сверх суточного лимита | Операция отклонена |
| Примечание | Суммы указаны в тенге, время — по Астане | |
