Перевыпуск карты : Требования

Создано Аналитик, последнее изменение 20.11.2026

В РАБОТЕ Статус документа.

1. Сценарий

  1. Клиент открывает карту и нажимает «Перевыпустить».
  2. Клиент выбирает причину; для причины «утеря» карта блокируется сразу.
Подробности проверки

Повторный заказ по той же карте запрещён, пока предыдущий не завершён.

Перевыпуск корпоративных карт в приложении не поддерживается.

2. Задачи релиза

  • Согласовать тарифы перевыпуска с казначейством
  • Подготовить тексты уведомлений для курьерской доставки
