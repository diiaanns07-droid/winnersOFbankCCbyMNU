# Округление покупок в копилку

Версия 0.9 от 20.11.2026, черновик для согласования.

## 1. Общие положения

### 1.1 Назначение

Функция переводит разницу между суммой покупки и ближайшей круглой суммой на накопительный счёт клиента, чтобы клиент копил без ручных действий.

### 1.2 Термины

- **Копилка** — накопительный счёт клиента в тенге, открытый в банке.
- **Шаг округления** — 100, 500 или 1 000 ₸.
- **Разница округления** — сумма, на которую покупка округляется вверх до шага.

### 1.3 Участники

| Система | Роль |
| --- | --- |
| Мобильное приложение | Подключение, отключение, история |
| Сервис округления | Расчёт разницы и ежедневный перевод |
| Карточный процессинг | Источник событий о проведённых покупках |
| Сервис счетов | Перевод с карты на копилку |

## 2. Функциональные требования

### 2.1 Подключение

- **ФТ-2.1.1.** Клиент с дебетовой картой в тенге подключает округление для одной карты и одной своей копилки.
- **ФТ-2.1.2.** Клиент выбирает шаг округления: 100, 500 или 1 000 ₸. По умолчанию шаг — 100 ₸.
- **ФТ-2.1.3.** Повторное подключение для той же карты заменяет шаг и копилку, накопленная за день сумма сохраняется.

### 2.2 Расчёт и перевод

- **ФТ-2.2.1.** Для каждой проведённой покупки по карте рассчитывается разница округления вверх до шага.
- **ФТ-2.2.2.** Если сумма покупки кратна шагу, разница равна нулю и в дневную сумму не добавляется.
- **ФТ-2.2.3.** Разницы за день суммируются и переводятся в копилку одним переводом в 23:00 по UTC+5.
  - **ФТ-2.2.3.1.** Если на карте недостаточно средств, перевод дня не выполняется и сумма переносится на следующий день.
  - **ФТ-2.2.3.2.** Перенос выполняется не более трёх дней подряд, после этого перенесённая сумма обнуляется.
- **ФТ-2.2.4.** Возврат покупки не уменьшает сумму, уже переведённую в копилку.

### 2.3 Отключение

- **ФТ-2.3.1.** Клиент отключает округление в любой момент; накопленная за день сумма переводится в 23:00 того же дня.
- **ФТ-2.3.2.** При закрытии копилки округление по всем картам клиента отключается автоматически.

### 2.4 История

- **ФТ-2.4.1.** Приложение показывает переводы в копилку за выбранный период не длиннее 90 дней.

## 3. Нефункциональные требования

- **НФТ-3.1.** Методы API отвечают не дольше 300 мс для 95 % запросов при нагрузке до 100 запросов в секунду.
- **НФТ-3.2.** Журнал переводов хранится 5 лет.
- **НФТ-3.3.** Доступность сервиса округления — не ниже 99,9 % в календарный месяц.

## 4. Данные

| Поле | Тип | Описание |
| --- | --- | --- |
| cardId | string | Идентификатор карты |
| boxId | string | Идентификатор копилки |
| step | integer | Шаг округления в тенге |
| pendingAmount | integer | Накоплено за день, в тиынах |
| carryDays | integer | Сколько дней подряд перевод переносится |

## 5. API

Все методы требуют заголовок `Authorization: Bearer <токен сессии клиента>`; карта и копилка должны принадлежать клиенту.

### 5.1 POST /roundup/subscriptions

Подключение или замена настройки округления.

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| cardId | string | да | Карта клиента |
| boxId | string | да | Копилка клиента |
| step | integer | да | 100, 500 или 1000 |

Ответ 201: `{"subscriptionId":"s-1","step":100}`.

### 5.2 GET /roundup/subscriptions/{cardId}

Чтение настройки. Ответ 200 содержит boxId, step и pendingAmount.

### 5.3 DELETE /roundup/subscriptions/{cardId}

Отключение округления. Ответ 204 без тела.

### 5.4 GET /roundup/history

Список переводов в копилку за период.

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| cardId | string | да | Карта клиента |
| from | date | да | Начало периода, ГГГГ-ММ-ДД |
| to | date | да | Конец периода, ГГГГ-ММ-ДД, не позже чем через 90 дней от начала |

Пример ответа:

```json
{"items":[{"date":"2026-11-20","amount":"350.00"}]}
```

### 5.5 Коды ответа

| Код | Когда возвращается |
| --- | --- |
| 200 | Запрос выполнен |
| 201 | Настройка создана или заменена |
| 204 | Настройка удалена |
| 400 | Неверный шаг или период длиннее 90 дней |
| 401 | Нет действующей сессии |
| 404 | Карта, копилка или настройка не найдена либо принадлежит другому клиенту |

## 6. Критерии приёмки

| № | Исходные условия | Действие | Ожидаемый результат |
| --- | --- | --- | --- |
| 1 | Шаг 100 ₸ | Покупка на 1 250 ₸ | Разница 50 ₸ добавлена к дневной сумме |
| 2 | Шаг 500 ₸ | Покупка на 1 000 ₸ | Разница 0 ₸, дневная сумма не изменилась |
| 3 | Дневная сумма 300 ₸, на карте 100 ₸ | 23:00 | Перевод не выполнен, перенос на следующий день |
| 4 | Перенос третий день подряд | 23:00, средств нет | Перенесённая сумма обнулена |
