# Корпоративный интернет-банк: требования к модулям

Сводный документ требований к двенадцати модулям. Версия 2.3 от 15.11.2026.

## 0. Общие требования

Все модули работают в едином интерфейсе корпоративного интернет-банка и используют общую модель прав.

Время во всех модулях — UTC+5; суммы — в тенге с двумя знаками после запятой, если не указано иное.

## 1. Модуль «Платёжные поручения»

### 1.1 Описание

Модуль обеспечивает создание платежей для сотрудников компании-клиента; каждый документ «платёжное поручение» проходит проверку прав и лимитов.

### 1.2 Требования

- **КИБ-1.1.** Сотрудник с правом «создание платежей» создаёт документ «платёжное поручение» в рамках своей компании.
- **КИБ-1.2.** Параметр «сумма» ограничен значением 100 000 000 ₸ включительно; превышение отклоняется с кодом 400.
- **КИБ-1.3.** Каждый документ «платёжное поручение» получает уникальный номер в формате PAY-ГГГГ-NNNNNN.
- **КИБ-1.4.** Изменение документа «платёжное поручение» после отправки на подписание запрещено; разрешена только отмена.
- **КИБ-1.5.** Отмена документа «платёжное поручение» возможна до начала исполнения банком и фиксируется в журнале действий.
- **КИБ-1.6.** Список документов «платёжное поручение» выводится постранично, по 50 записей, сортировка по дате создания, новые сверху.
- **КИБ-1.7.** Все операции модуля «Платёжные поручения» записываются в журнал с идентификатором сотрудника и временем по UTC+5.

### 1.3 Метод POST /corp/v1/payments

| Поле | Значение |
| --- | --- |
| REST type | POST |
| Request URL | /corp/v1/payments |
| Authorization | Bearer, сессия сотрудника с правом «создание платежей» |

#### 1.3.1 Параметры запроса

| Parameter | Format | Mandatory | Description |
| --- | --- | --- | --- |
| companyId | string | Да | Идентификатор компании |
| documentId | string | Нет | Номер документа при изменении |
| value | integer | Да | Сумма, не более 100 000 000 ₸ |
| comment | string | Нет | Комментарий сотрудника, до 255 символов |

#### 1.3.2 Коды ответа

| Код | Когда возвращается |
| --- | --- |
| 200 | Запрос выполнен |
| 400 | Параметр «сумма» вне допустимого диапазона |
| 403 | У сотрудника нет нужного права |
| 404 | Документ не найден или принадлежит другой компании |

### 1.4 Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| --- | --- | --- |
| Сотрудник с правом «создание платежей» | Создать документ «платёжное поручение» со значением 100 000 000 ₸ | Документ создан, номер присвоен |
| Сотрудник без права «создание платежей» | Создать документ «платёжное поручение» | Ответ 403 |
| Документ на подписании | Изменить документ | Изменение отклонено, документ не изменился |
