# Требования к модулю выгрузки выписок

| Поле | Значение |
| --- | --- |
| Система | Интернет-банк для бизнеса |
| Заказчик | Департамент малого бизнеса |
| Статус | Черновик |

## 1. Назначение

Модуль формирует выписку по расчётному счёту юридического лица за выбранный период и отдаёт её в форматах PDF и 1С.

## 2. Функциональные требования

| ID | Требование | Источник |
| --- | --- | --- |
| REQ-001 | Пользователь выбирает счёт и период выписки не длиннее 366 дней | Интервью с клиентами |
| REQ-002 | Выписка содержит входящий и исходящий остаток, обороты и все операции за период | Регламент банка |
| REQ-003 | Формат 1С соответствует стандарту обмена 1CClientBankExchange версии 1.03 | Требование клиентов |
| REQ-004 | Выписка за период больше 90 дней формируется асинхронно, пользователь получает уведомление о готовности | Нагрузка на систему |
| REQ-005 | Подписанная выписка содержит электронную подпись банка | Регламент банка |

## 3. Требования к данным

3.1. Операции берутся из АБС на момент запроса; операции текущего дня помечаются как предварительные.

3.2. Суммы показываются в валюте счёта с двумя знаками после запятой.

## 4. Ограничения

4.1. Не больше 10 запросов выписки в минуту на одного пользователя.

4.2. Файл выписки хранится 30 дней, затем удаляется.

## Приложение А. Пример строки выписки

```
01.03.2026 | Поступление | 150 000,00 | ТОО «Альфа» | Оплата по счёту 12
```
