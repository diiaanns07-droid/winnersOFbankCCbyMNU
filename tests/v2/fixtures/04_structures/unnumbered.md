# Оповещение о входе с нового устройства

Документ подготовлен командой цифровых каналов. Номера требованиям не присвоены.

## Зачем это нужно

Клиенты не узнают о том, что в их интернет-банк вошли с чужого устройства, пока не обнаружат списания. Нужно сообщать клиенту о каждом входе с устройства, которое раньше не использовалось, и дать возможность сразу заблокировать доступ.

## Как это должно работать

Устройство считается новым, если его идентификатор не встречался во входах клиента за последние 180 дней. Идентификатор устройства формирует мобильное приложение или браузер при первом запуске.

При успешном входе с нового устройства банк отправляет клиенту сообщение в приложение на все остальные устройства клиента и SMS на основной номер телефона. В сообщении указываются дата и время входа по UTC+5, тип устройства, город по IP-адресу и кнопка «Это не я».

Если клиент нажимает «Это не я», банк завершает все сессии клиента, кроме сессии устройства, с которого нажата кнопка, и блокирует вход с нового устройства на 24 часа. Клиент получает подтверждение блокировки и номер контакт-центра.

Если клиент не реагирует на сообщение, никаких действий не выполняется.

Сообщения о входе не отправляются чаще одного раза в 10 минут для одного и того же нового устройства.

Клиент не может отключить эти сообщения в настройках.

## Что видит клиент

На экране «Безопасность» отображается список устройств, с которых выполнялся вход за последние 180 дней:

- название устройства и операционная система;
- дата и время последнего входа;
- город по IP-адресу последнего входа;
- кнопка «Завершить сеанс» для каждого устройства, кроме текущего.

Список отсортирован по дате последнего входа, новые сверху.

## Порядок обработки входа

1. Сервис аутентификации проверяет логин и пароль клиента.
2. Сервис аутентификации передаёт идентификатор устройства в сервис устройств.
3. Сервис устройств определяет, новое ли устройство.
4. Для нового устройства сервис уведомлений отправляет сообщения в приложение и SMS.
5. Сервис устройств сохраняет вход в журнал.

## Ограничения

Сообщение должно уйти клиенту не позднее 30 секунд после успешного входа. Журнал входов хранится три года. Город по IP-адресу определяется внешним справочником, при недоступности справочника вместо города пишется «не определён».

## Данные

Для каждого входа хранятся идентификатор клиента, идентификатор устройства, тип устройства, IP-адрес, город, дата и время входа, признак нового устройства и признак нажатия «Это не я».

## Взаимодействие с другими системами

Приложение получает список устройств методом GET /security/devices и завершает сеанс методом DELETE /security/devices/{deviceId}. Нажатие «Это не я» передаётся методом POST /security/devices/{deviceId}/reject.

Ответ метода списка устройств:

| Поле | Тип | Описание |
| --- | --- | --- |
| deviceId | string | Идентификатор устройства |
| name | string | Название устройства |
| lastLoginAt | string | Дата и время последнего входа по UTC+5 |
| city | string | Город или «не определён» |
| current | boolean | Текущее устройство |

Метод завершения сеанса возвращает 204, если сеанс завершён, и 404, если устройство не найдено или принадлежит другому клиенту. Попытка завершить текущий сеанс возвращает 409.

## Как проверить

- Вход с телефона, которого не было в журнале, приводит к сообщению на планшет клиента и SMS.
- Повторный вход с того же телефона через 5 минут не приводит к новому сообщению.
- Нажатие «Это не я» на планшете завершает сеанс на телефоне, сеанс на планшете остаётся.
- Вход с устройства, которое использовалось 200 дней назад, считается входом с нового устройства.
