# ТЗ: Лимит на снятие наличных по дебетовой карте

**Версия:** 2.0 · **Дата:** 20.11.2026 · **Владелец:** продукт «Дебетовые карты»

## 1. Требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| ТР-01 | Клиент задаёт дневной лимит снятия наличных от 10 000 до 1 000 000 ₸ включительно. | Высокий |
| ТР-02 | Лимит действует с момента сохранения; сутки считаются по времени Астаны (UTC+5) с 00:00 до 23:59. | Высокий |
| ТР-03 | Снятие, после которого сумма снятий за сутки превысит лимит, отклоняется банкоматом. Повторное сохранение того же лимита возвращает 409. | Высокий |
| ТР-04 | Приложение показывает текущий лимит и сумму снятий за сегодня. | Средний |
| ТР-05 | Суммы в API передаются в тенге. | Средний |

## 2. Нефункциональные требования

| ID | Требование |
| :--- | :--- |
| НФ-01 | Время ответа API — не более 800 мс для 95 % запросов при 30 запросах в секунду. |

## 3. API

Эндпоинт сохранения: `GET /cards/{cardId}/cash-limit/save`.

Тело запроса:

```json
{"dailyLimit": 5000000}
```

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `dailyLimit` | integer | Дневной лимит в тиынах, от 1 000 000 до 100 000 000 |

Пример ответа 200:

```json
{"dailyLimit": 5000000, "spentToday": 1200000}
```

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `dailyLimit` | string | Сохранённый лимит в тиынах |
| `spentToday` | integer | Сумма снятий за сегодня в тиынах |

| Код | Когда |
| :--- | :--- |
| 200 | Лимит сохранён или прочитан |
| 400 | Лимит вне диапазона |
| 401 | Нет сессии клиента |
| 404 | Карта не найдена или принадлежит другому клиенту |
