# Управление избранными получателями

Версия 0.3 от 12.10.2026.

## 1. Требования

1. FR-01. Клиент добавляет получателя в избранное из истории переводов.
2. FR-02. Клиент удаляет получателя из избранного.
3. FR-03. Приложение показывает список избранных получателей, отсортированный по дате добавления.
4. FR-04. Хранить сумму последнего перевода в копейках и лимит избранного в рублях.

## 2. API

### GET /v1/favorites/delete

Удаление получателя из избранного. Параметр `recipientId` передаётся в строке запроса.

**Content-Type:** application/json

Тело запроса отсутствует.

| Поле | Тип | Обязательное | Описание |
| --- | --- | --- | --- |
| recipientId | integer | да | Идентификатор получателя |

Ответ:

| Поле | Тип | Описание |
| --- | --- | --- |
| recipientId | string | Идентификатор удалённого получателя |

### POST /v1/favorites

Добавление получателя. Если получатель уже в избранном, вернуть 409.

### Коды ответа

* 200 OK — операция выполнена.
* 400 Bad Request — неверные параметры.
* 404 Not Found — получатель не найден. Для чужого получателя возвращается 403.
