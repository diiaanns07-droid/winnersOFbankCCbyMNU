# Доставка банковской карты курьером

Версия 1.2 от 10.11.2026. Согласовано: руководитель направления карт.

## 1. Бизнес-требования

ТР-1: Клиент оформляет доставку выпущенной карты на адрес из анкеты.
ТР-2: Курьер привозит карту в выбранное клиентом окно доставки.
ТР-3: Если клиент не получил карту, она хранится в отделении. Срок хранения карты в отделении — 30 дней, затем карта уничтожается.
ТР-4: За повторную доставку банк начисляет плату; ставка пени за просрочку оплаты — 0,1 % в день.

## 2. Нефункциональные требования

НФ-1: Методы API отвечают не дольше 1 с для 95 % запросов; доступность — 99,5 % в месяц.

## 3. Интеграция

Мобильное приложение создаёт заявку на доставку, переносит дату доставки и получает статус заявки через REST API.

## 4. API

### POST /deliveries — Создание заявки на доставку

| Поле | Тип | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `cardId` | string | 1–64 | Идентификатор выпущенной карты |
| `storagePeriod` | integer | 1–30 | Срок хранения карты в отделении, в днях |
| `penaltyRate` | number | 0–1 | Ставка пени, % в день |

Ответ 201 — заявка создана. Ответ 400 — неверные параметры.

### PATCH /deliveries/{id} — Изменение заявки

| Поле | Тип | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `date` | string | ГГГГ-ММ-ДД | Новая дата доставки |

Ответ 200 — дата изменена. Ответ 404 — заявка не найдена.

### GET /deliveries/{id} — Статус заявки

| Поле | Тип | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `status` | string | NEW / DONE | Статус заявки |

Ответ 200 — статус заявки. Ответ 404 — заявка не найдена.
