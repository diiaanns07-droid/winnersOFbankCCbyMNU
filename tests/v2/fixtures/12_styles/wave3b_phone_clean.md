# Перевод по номеру телефона

| Поле | Значение |
| :--- | :--- |
| **Наименование** | Перевод клиенту банка по номеру телефона |
| **Продукт** | Мобильный банк |
| **Бизнес-процесс** | Переводы между физическими лицами |
| **Тип работы** | Новый функционал |
| **Влияние на ИС** | Мобильный банк, сервис переводов, справочник клиентов, антифрод |
| **Версия документа** | 1.1 от 15.11.2026 |

## Часть A. Новый функционал

### Цели
Клиент переводит деньги другому клиенту банка, зная только номер его телефона.

### Архитектура решения
Мобильное приложение → сервис переводов → справочник клиентов. Сервис переводов → антифрод.

### Функциональные требования
* **Ф-1.** Получатель ищется по номеру телефона в формате +7XXXXXXXXXX; если номер привязан к нескольким картам получателя, деньги зачисляются на основную карту получателя.
* **Ф-2.** Перед подтверждением отправитель видит имя получателя в виде «Имя Ф.» и сумму перевода.
* **Ф-3.** Сумма одного перевода — от 100 ₸ до 1 000 000 ₸ включительно. Сумма переводов отправителя за календарные сутки по времени Астаны (UTC+5) — не больше 3 000 000 ₸.
* **Ф-4.** Комиссия не взимается.
* **Ф-5.** Если антифрод отклонил перевод, деньги не списываются, отправитель видит сообщение «Перевод отклонён службой безопасности».
* **Ф-6.** Отменить выполненный перевод в приложении нельзя; спорный перевод клиент оспаривает через контакт-центр в течение 30 календарных дней, ответ банк даёт в течение 15 рабочих дней.

### Нефункциональные требования
* **НФ-1.** Поиск получателя отвечает не дольше 1 с, перевод — не дольше 5 с для 95 % запросов при нагрузке до 200 запросов в секунду.
* **НФ-2.** Номер телефона получателя в журналах сервиса маскируется: видны только последние 4 цифры.

### Требования к данным
Хранить идентификатор перевода, идентификаторы карт отправителя и получателя, сумму в тиынах, время перевода по UTC+5 и статус.

### Интеграция
Приложение ищет получателя и выполняет перевод через дочерний документ «Перевод по номеру телефона — REST API».

### Критерии приемки
| Дано | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Отправитель сегодня переводов не делал | Перевести 1 000 000 ₸ | Перевод выполнен |
| Отправитель сегодня перевёл 2 500 000 ₸ | Перевести 600 000 ₸ | Отказ «Превышен суточный лимит переводов» |
| Получатель не найден | Ввести номер +77000000000 | Сообщение «Получатель не найден» |
| Антифрод отклонил перевод | Подтвердить перевод 5 000 ₸ | Деньги не списаны, сообщение «Перевод отклонён службой безопасности» |

## Часть B. Перевод по номеру телефона — REST API

Суммы во всех методах передаются в тиынах: 1 ₸ = 100 тиынов.

### Метод 1. Поиск получателя

| Поле | Значение |
| :--- | :--- |
| **REST type** | GET |
| **Request URL** | `https://api.bank.local/p2p/recipients?phone={phone}` |

#### Логика работы метода
1. Проверить сессию отправителя; если сессии нет, вернуть 401.
2. Проверить формат номера; если номер не в формате +7XXXXXXXXXX, вернуть 400.
3. Найти клиента по номеру; если не найден, вернуть 404.
4. Вернуть 200 и имя получателя в виде «Имя Ф.».

#### Статусы ответа
* 200. Получатель найден.
* 400. Неверный формат номера.
* 401. Нет действующей сессии.
* 404. Получатель не найден.

### Метод 2. Перевод

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **Request URL** | `https://api.bank.local/p2p/transfers` |
| **Content-Type** | application/json |

#### Параметры запроса
| Параметр | Тип | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `phone` | string | Да | Номер телефона получателя, +7XXXXXXXXXX |
| `amount` | integer | Да | Сумма перевода в тиынах, от 10 000 до 100 000 000 |
| `cardId` | string | Да | Идентификатор карты отправителя |

#### Логика работы метода
1. Проверить сессию отправителя; если сессии нет, вернуть 401.
2. Проверить сумму: от 10 000 до 100 000 000 тиынов включительно; иначе вернуть 400.
3. Проверить суточную сумму переводов отправителя с учётом нового перевода: не больше 300 000 000 тиынов; иначе вернуть 422.
4. Найти получателя; если не найден, вернуть 404.
5. Передать перевод в антифрод; при отказе вернуть 403.
6. Списать сумму с карты отправителя, зачислить на основную карту получателя и вернуть 200.

#### Статусы ответа
* 200. Перевод выполнен.
* 400. Неверная сумма.
* 401. Нет действующей сессии.
* 403. Перевод отклонён антифродом.
* 404. Получатель не найден.
* 422. Превышен суточный лимит переводов.

#### Ответ
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `transferId` | string | Идентификатор перевода |
| `amount` | integer | Сумма перевода в тиынах |

Пример ответа 200:
```json
{"transferId": "t-90211", "amount": 500000}
```
