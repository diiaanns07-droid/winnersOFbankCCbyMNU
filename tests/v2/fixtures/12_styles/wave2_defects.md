# Напоминание о платеже по кредиту

Версия 1.2 от 10.11.2026.

## Часть A. Требования

### Функциональные требования
* **НП-1.** Клиент задаёт сумму напоминания от 1 000 до 300 000 ₸ включительно.
* **НП-2.** Напоминание приходит за 3 календарных дня до даты платежа.
* **НП-3.** Отключённое напоминание не отправляется.
* **НП-4.** Отключённое напоминание отправляется в день платежа.

### Нефункциональные требования
* **НФ-1.** Экран напоминаний открывается быстро и всегда показывает актуальные данные.

### Требования к данным
Хранить идентификатор кредита, сумму напоминания в тенге и интервал `retryDelay` в минутах.

### Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Кредит активен | Задать сумму 300 000 ₸ | Отказ: сумма превышает максимальную |
| Кредит активен | Задать сумму 5 000 ₸ | Напоминание сохранено |

## Часть B. REST API

### Метод setReminder

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **Request URL** | `/loans/{loanId}/reminder` |

#### Логика метода
1. Если кредит закрыт, вернуть 200 с `status` = `CLOSED`.
2. Повторить отправку через `retryDelay` секунд.

#### Ответ

| Parameter | Format | Description |
| :--- | :--- | :--- |
| `nextDate` | string | Дата напоминания, ДД.ММ.ГГГГ |
| `daysBefore` | integer | Количество рабочих дней до даты платежа |

Пример: `{"nextDate":"2026-12-07","daysBefore":3}`.

### Статусы

| Код | Когда возвращается | Тело ответа |
| :--- | :--- | :--- |
| 200 | Запрос выполнен | Описано в разделе метода |
| 400 | Сумма вне диапазона | `{"message":"Проверьте сумму"}` |
| 409 | Кредит закрыт, напоминание недоступно | `{"message":"Кредит закрыт"}` |
