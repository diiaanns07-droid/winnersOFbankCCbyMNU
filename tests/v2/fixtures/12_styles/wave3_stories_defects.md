## 1. Цель

Клиент подаёт заявку на кредитную карту в мобильном приложении и узнаёт решение банка без визита в отделение.

## 2. Пользовательские истории

* **ИП-1.** Как клиент, я хочу подать заявку на карту с лимитом от 50 000 до 3 000 000 ₸, чтобы получить карту без визита в отделение.
* **ИП-2.** Как клиент, я хочу видеть статус заявки, чтобы знать, когда забрать карту.
* **ИП-3.** Как клиент, я хочу отозвать заявку до решения банка.

## 3. Бизнес-правила

* **БП-1.** Лимит карты — целое число тенге от 50 000 до 3 000 000 включительно. Значение вне диапазона отклоняется с кодом 400.
* **БП-2.** У клиента может быть не больше одной заявки в статусе «На рассмотрении». Повторная заявка отклоняется с кодом 409.
* **БП-3.** Решение по заявке принимается не позднее 15 минут после подачи; срок действия заявки — 15 минут. Время — по Астане (UTC+5).
* **БП-4.** Отозвать заявку можно только в статусе «На рассмотрении».
* **БП-5.** В базе лимит хранится в тиынах: 1 ₸ = 100 тиынов.

## 4. Сценарии приёмки

```gherkin
Сценарий: заявка с лимитом на границе
  Дано клиент без заявок
  Когда клиент подаёт заявку с лимитом 3 000 000 ₸
  Тогда заявка создана со статусом «На рассмотрении»

Сценарий: повторная заявка
  Дано у клиента есть заявка «На рассмотрении»
  Когда клиент подаёт новую заявку
  Тогда ответ 409, вторая заявка не создана
```

## 5. Нефункциональные требования

* **НФ-1.** Методы API отвечают не дольше 2 с для 95 % запросов при нагрузке до 20 запросов в секунду.
* **НФ-2.** Сервис заявок доступен круглосуточно и без сбоев.

## 6. Интеграция

Мобильное приложение создаёт заявку, получает её статус и отзывает заявку через REST API.

## 7. REST API

### 7.1. Создание заявки

**Метод:** POST
**Путь:** /card-applications

| Имя | Тип | Обязательное | Описание |
| :--- | :--- | :--- | :--- |
| `limit` | integer | да | Запрошенный лимит карты в тенге, от 50 000 до 3 000 000 |
| `term` | integer | да | Срок действия заявки, в часах (1–15) |
| `productCode` | string | да | Код продукта карты |

Коды ответа:
- `201` — заявка создана, в теле `applicationId` и `status`.
- `400` — лимит вне диапазона или не указан продукт.
- `409` — у клиента уже есть заявка «На рассмотрении».

### 7.2. Статус заявки

**Метод:** GET
**Путь:** /card-applications/{applicationId}

| Имя | Тип | Обязательное | Описание |
| :--- | :--- | :--- | :--- |
| `applicationId` | string | да | Идентификатор заявки |

Коды ответа:
- `200` — статус заявки: `PENDING`, `APPROVED`, `DECLINED` или `WITHDRAWN`.
- `404` — заявка не найдена или принадлежит другому клиенту.
