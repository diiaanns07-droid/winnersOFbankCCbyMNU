# Спецификация требований: уведомления о поступлении зарплаты

Версия 1.0 от 12.11.2026. Подготовил: аналитик команды уведомлений.

## 1. Введение

### 1.1. Назначение
Документ описывает требования к push-уведомлению клиента о поступлении зарплаты на карту и к настройке этого
уведомления в мобильном приложении.

### 1.2. Термины
* **Зарплатное поступление** — зачисление на карту клиента с кодом назначения платежа 010 (заработная плата).
* **Настройка уведомления** — признак «Уведомлять о зарплате» (включено или выключено) по карте клиента.

## 2. Функциональные требования

3.1.1. Система должна отправлять клиенту push «Зарплата зачислена: N ₸» не позднее 60 секунд после того, как
процессинг передал событие о зарплатном поступлении.

3.1.2. Система должна отправлять push только по картам, у которых настройка уведомления включена.

3.1.3. Приложение должно показывать на экране карты переключатель «Уведомлять о зарплате» с текущим значением
настройки и сохранять новое значение по нажатию переключателя.

3.1.4. По умолчанию настройка уведомления включена.

3.1.5. Повторное событие о том же зачислении (тот же идентификатор операции) не должно приводить к повторному push.

## 3. Нефункциональные требования

3.2.1. Методы API настройки отвечают не дольше 500 мс для 95 % запросов при нагрузке до 100 запросов в секунду.

3.2.2. Сервис уведомлений хранит идентификаторы обработанных операций 7 календарных дней.

## 4. Интеграция

Приложение читает и сохраняет настройку уведомления методами API ниже. Процессинг передаёт событие о зачислении в
сервис уведомлений через брокер сообщений; формат события описан в документе процессинга.

## 5. API

```yaml
openapi: 3.0.3
paths:
  /cards/{cardId}/salary-notification:
    get:
      summary: Получить настройку уведомления
      responses:
        "200": {description: Настройка уведомления}
        "404": {description: Карта не найдена или принадлежит другому клиенту}
    put:
      summary: Сохранить настройку уведомления
      requestBody:
        content:
          application/json:
            schema: {type: object, properties: {enabled: {type: boolean}}, required: [enabled]}
      responses:
        "200": {description: Настройка сохранена}
        "400": {description: Неверное тело запроса}
        "404": {description: Карта не найдена или принадлежит другому клиенту}
```

## 6. Критерии приёмки

| № | Дано | Действие | Результат |
| :--- | :--- | :--- | :--- |
| 1 | Настройка включена | Поступила зарплата 350 000 ₸ | Push «Зарплата зачислена: 350 000 ₸» не позднее 60 секунд |
| 2 | Настройка выключена | Поступила зарплата | Push не отправлен |
| 3 | Push по операции уже отправлен | Повторное событие о той же операции | Повторного push нет |
| 4 | Карта клиента | Выключить переключатель | GET возвращает `enabled: false` |
