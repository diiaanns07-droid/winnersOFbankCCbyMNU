# Кредитные каникулы: заявка в приложении

**Версия:** 3.2, 10.11.2026. **Владелец:** управление розничного кредитования.

## 1. Назначение

Документ описывает подачу заявки на кредитные каникулы по кредиту наличными в мобильном приложении и
проверку заявки. Каникулы — отсрочка платежей по основному долгу на срок от 1 до 6 месяцев.

## 2. Требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| КК-1 | Заявку можно подать по действующему кредиту наличными без просрочки на дату подачи. | Высокий |
| КК-2 | Клиент выбирает срок каникул целым числом месяцев от 1 до 6 включительно. | Высокий |
| КК-3 | По одному кредиту каникулы предоставляются не чаще одного раза за 12 месяцев, считая от даты окончания прошлых каникул. | Высокий |
| КК-4 | Банк рассматривает заявку не дольше 3 рабочих дней с даты подачи; результат приходит push и виден в разделе «Заявки». | Средний |
| КК-5 | Каникулы начинаются с даты ближайшего планового платежа после одобрения заявки. | Высокий |
| КК-6 | Клиент может отозвать заявку, пока она в статусе «На рассмотрении». | Средний |
| КК-7 | Проценты за срок каникул начисляются по ставке договора и распределяются равными частями на оставшиеся платежи после каникул. | Высокий |
| КК-8 | Уведомление об одобрении содержит дату начала, дату окончания каникул и новую сумму платежа. | Средний |

Статусы заявки: «На рассмотрении» → «Одобрена» или «Отказ»; из «На рассмотрении» клиент может перевести заявку в «Отозвана».
Даты в заявке — по времени Астаны (UTC+5).

## 3. Нефункциональные требования

| ID | Требование |
| :--- | :--- |
| НФ-1 | Создание и отзыв заявки отвечают не дольше 2 с для 95 % запросов при нагрузке до 30 запросов в секунду. |
| НФ-2 | Заявки и решения по ним хранятся 5 лет. |

## 4. Критерии приёмки

| № | Сценарий | Ожидаемый результат |
| :--- | :--- | :--- |
| 1 | Кредит без просрочки, срок 6 месяцев | Заявка создана в статусе «На рассмотрении» |
| 2 | Срок 7 месяцев | Ошибка «Срок каникул — от 1 до 6 месяцев» |
| 3 | Прошлые каникулы закончились 11 месяцев назад | Ошибка «Каникулы доступны раз в 12 месяцев» |
| 4 | Заявка «На рассмотрении», клиент отзывает | Статус «Отозвана» |
| 5 | Заявка «Одобрена», клиент пытается отозвать | Ошибка «Одобренную заявку отозвать нельзя» |

## 5. API

Эндпоинт создания заявки: POST /loans/{loanId}/holidays — тело `{"months": 6}`; ответ 201 с `applicationId`.
Коды ответа: 201 — заявка создана; 400 — срок вне диапазона 1–6; 404 — кредит не найден или принадлежит другому клиенту; 409 — есть просрочка или каникулы уже были в последние 12 месяцев.

Эндпоинт отзыва заявки: POST /holidays/{applicationId}/withdraw — без тела; ответ 200.
Коды ответа: 200 — заявка отозвана; 404 — заявка не найдена; 409 — заявка не в статусе «На рассмотрении».

Эндпоинт чтения заявок: GET /loans/{loanId}/holidays — ответ 200 со списком заявок: `applicationId`, `months`, `status`, `startDate`, `endDate`, `newPayment` (в тенге, с двумя знаками после запятой).
Коды ответа: 200 — список заявок; 404 — кредит не найден или принадлежит другому клиенту.
