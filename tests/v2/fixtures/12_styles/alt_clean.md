# Управление избранными получателями

Версия 1.0 от 12.10.2026.

## 1. Требования

1. FR-01. Клиент добавляет получателя в избранное из истории переводов.
2. FR-02. Клиент удаляет получателя из избранного.
3. FR-03. Приложение показывает список избранных получателей методом listFavorites, отсортированный по дате добавления.
4. FR-04. Хранить сумму последнего перевода в копейках; 1 рубль = 100 копеек.

## 2. API

### DELETE /v1/favorites/{recipientId}

Удаление получателя из избранного. Тело запроса отсутствует.

### POST /v1/favorites

Добавление получателя. Если получатель уже в избранном, вернуть 409.

**Content-Type:** application/json

| Поле | Тип | Обязательное | Описание |
| --- | --- | --- | --- |
| recipientId | string | да | Идентификатор получателя |

Ответ:

| Поле | Тип | Описание |
| --- | --- | --- |
| recipientId | string | Идентификатор добавленного получателя |

### GET /v1/favorites (listFavorites)

Список избранных получателей.

### Коды ответа

* 200 OK — операция выполнена.
* 400 Bad Request — неверные параметры.
* 404 Not Found — получатель не найден или принадлежит другому клиенту.
* 409 Conflict — получатель уже в избранном.
