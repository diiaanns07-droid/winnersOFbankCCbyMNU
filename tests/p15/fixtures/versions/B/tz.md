# Уведомление о расходах по карте

## Функциональные требования
* **Ф-1.** Порог задаётся целым числом от 1 000 до 1 000 000 ₸.
* **Ф-3.** Когда расходы достигают порога, клиент получает push. На карту приходится максимум один такой push за календарный месяц.
* **Ф-4.** При изменении порога накопленная сумма сохраняется. Если она ниже нового порога, следующее достижение вызывает push независимо от истории предыдущей настройки.

## Ответ API
Если результат 400, 401 и далее — неуспешный.
