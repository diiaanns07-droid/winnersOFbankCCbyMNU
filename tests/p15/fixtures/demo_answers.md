# Демонстрационные ответы команды для показа жюри

Файл подключается флагом `--demo-answers tests/p15/fixtures/demo_answers.md`.
Раздел `## …` — ID вопроса или ключевые слова через запятую: ответ предлагается в вопросе,
где встречаются все ключевые слова. Строка «Правка» заполняет поле правки текста: из неё
движок пишет редакцию B. Строка «Источник ответа» показывается рядом с кнопкой
и попадает в answers.md новой редакции, чтобы было видно: это не решение банка.
