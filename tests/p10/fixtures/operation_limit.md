# Лимит одной операции перевода

## Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Лимит суммы одной операции перевода |
| **Продукт** | Мобильный банк, учебный кейс |
| **Влияние на ИС** | Мобильный банк, сервис переводов |

## Цели

Ограничить сумму одного перевода с карты на карту.

## Функциональные требования

* **Л-1.** Сумма одной операции перевода — до 500 000 ₸. Сумма задаётся целым числом тенге.
* **Л-2.** Перевод сверх лимита отклоняется с сообщением «Превышен лимит операции».

## Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| На карте 600 000 ₸ | Перевести 100 000 ₸ | Перевод выполнен |
