# Кэшбэк за покупки в выбранных категориях

## Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Кэшбэк в выбранных категориях |
| **Влияние на ИС** | Мобильный банк, сервис лояльности |

## Функциональные требования

* **КБ-1.** Клиент выбирает от 1 до 3 категорий кэшбэка включительно.
* **КБ-2.** Кэшбэк начисляется в размере 5% от суммы покупки в выбранной категории.
* **КБ-3.** Сумма кэшбэка за месяц не более 10 000 ₸.

## Требования к интеграции

Приложение сохраняет категории через REST API `GET /cashback/setCategories`.

## Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Выбрана категория «Кафе», кэшбэк за месяц 0 ₸ | Покупка в кафе на 20 000 ₸ | Начислено 1 000 ₸ |
