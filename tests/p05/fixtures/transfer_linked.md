# Подтверждение перевода

## Общие правила

- **ОП-1.** Операция подтверждается одноразовым кодом не позднее 120 секунд с момента отправки кода; по истечении срока операция отклоняется с кодом CONFIRM_TIMEOUT.

## Переводы между картами

### Функциональные требования

- **ПР-1.** Клиент подтверждает перевод в установленный срок по правилу ОП-1.
- **ПР-2.** На экране подтверждения есть кнопка «Подтвердить быстро»; нажатие отправляет одноразовый код на номер телефона клиента.
