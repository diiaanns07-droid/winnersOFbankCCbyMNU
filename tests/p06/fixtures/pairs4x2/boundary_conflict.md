# Резерв суммы при бронировании отеля

Учебный документ №06: резервирование суммы на карте.

## Часть A. Бизнес-требования

### Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Резерв суммы по запросу партнёра |
| **Продукт** | Эквайринг партнёров |
| **Версия документа** | 1.0 от 16.11.2026 |

### Функциональные требования
* **РС-1.** При бронировании отеля партнёр запрашивает резерв суммы на карте клиента.
* **РС-2.** Банк резервирует на карте сумму от 1 000 до 2 000 000 ₸ включительно.
* **РС-3.** Резерв снимается автоматически, если партнёр не списал сумму в течение 30 суток после резервирования.
* **РС-4.** Партнёр может снять резерв частично или полностью до списания.

### Требования к интеграции
Партнёр создаёт резерв методом createHold и снимает его методом releaseHold. Методы описаны в части B.

### Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| На карте 3 000 000 ₸ | Партнёр запрашивает резерв 1 500 000 ₸ | Резерв 1 500 000 ₸ создан |
| На карте 3 000 000 ₸ | Партнёр запрашивает резерв 500 ₸ | Резерв отклонён |

## Часть B. REST API

### Метод createHold

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **Request URL** | `/holds` |
| **Authorization** | Подпись партнёра |

#### Тело запроса

| Parameter | Format | Mandatory | Logic | Description |
| :--- | :--- | :--- | :--- | :--- |
| `cardToken` | string | Да | Токен карты | Карта клиента |
| `amount` | integer | Да | См. логику метода | Сумма резерва в тенге |

#### Логика метода
1. Проверить токен карты и доступный остаток.
2. Сумма резерва должна быть не меньше 1 000 ₸ и строго меньше 2 000 000 ₸, иначе вернуть 400.
3. Создать резерв и вернуть 200.

### Метод releaseHold

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **Request URL** | `/holds/{holdId}/release` |
| **Authorization** | Подпись партнёра |

#### Логика метода
1. Найти резерв по `holdId`.
2. Сумма снятия не может быть больше остатка резерва, иначе вернуть 400.
3. Уменьшить резерв и вернуть 200.

### Статусы

| Код | Когда возвращается | Тело ответа |
| :--- | :--- | :--- |
| 200 | Запрос выполнен | `{"holdId":"h-1","amount":1500000}` |
| 400 | Сумма вне допустимых значений | `{"message":"Проверьте сумму"}` |
| 404 | Резерв не найден | `{"message":"Не найдено"}` |
