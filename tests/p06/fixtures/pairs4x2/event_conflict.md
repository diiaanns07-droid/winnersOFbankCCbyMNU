# Возврат покупки по карте

Учебный документ №06: возврат покупки.

## Часть A. Бизнес-требования

### Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Зачисление возврата покупки |
| **Продукт** | Карточный процессинг |
| **Версия документа** | 1.0 от 14.11.2026 |

### Функциональные требования
* **ВП-1.** Клиент оформляет возврат покупки в магазине, а магазин отправляет банку запрос на возврат.
* **ВП-2.** Когда магазин подтверждает возврат, банк зачисляет сумму возврата на карту, которой оплачена покупка.
* **ВП-3.** Сумма возврата не может быть больше суммы исходной покупки.
* **ВП-4.** После зачисления клиент получает push «Возврат зачислен» с суммой возврата.

### Нефункциональные требования
* **НФ-1.** Зачисление выполняется не позднее 1 часа после подтверждения возврата для 99 % возвратов.

### Требования к интеграции
Магазин передаёт возврат методом createRefund, приложение читает состояние возврата методом getRefund. После подтверждения возврата магазином сумма возврата зачисляется на бонусный счёт клиента, а остаток карты не меняется.

### Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Покупка картой на 15 000 ₸ | Магазин подтверждает возврат 15 000 ₸ | На карту зачислено 15 000 ₸, push «Возврат зачислен» |
| Покупка картой на 15 000 ₸ | Магазин запрашивает возврат 20 000 ₸ | Возврат отклонён |

## Часть B. REST API

### Метод createRefund

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **Request URL** | `/refunds` |
| **Authorization** | Подпись магазина |

#### Тело запроса

| Parameter | Format | Mandatory | Logic | Description |
| :--- | :--- | :--- | :--- | :--- |
| `purchaseId` | string | Да | Исходная покупка | Идентификатор покупки |
| `amount` | integer | Да | Не больше суммы покупки | Сумма возврата в тенге |

#### Логика метода
1. Найти исходную покупку по `purchaseId`.
2. Если сумма возврата больше суммы покупки, вернуть 422.
3. Сохранить возврат и вернуть 200.

### Метод getRefund

| Поле | Значение |
| :--- | :--- |
| **REST type** | GET |
| **Request URL** | `/refunds/{refundId}` |
| **Authorization** | Bearer, сессия клиента |

### Статусы

| Код | Когда возвращается | Тело ответа |
| :--- | :--- | :--- |
| 200 | Запрос выполнен | Описано в разделе метода |
| 404 | Покупка или возврат не найдены | `{"message":"Не найдено"}` |
| 422 | Сумма возврата больше суммы покупки | `{"message":"Сумма возврата больше покупки"}` |
