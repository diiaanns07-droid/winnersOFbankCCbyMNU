# Перевод на карту другого банка

Учебный документ №06: комиссия за перевод.

## Часть A. Бизнес-требования

### Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Перевод с карты на карту другого банка |
| **Продукт** | Мобильный банк |
| **Версия документа** | 1.0 от 12.11.2026 |

### Функциональные требования
* **ПК-1.** Клиент переводит деньги со своей карты KZT на карту другого банка по номеру карты получателя.
* **ПК-2.** Сумма перевода задаётся целым числом от 1 000 до 1 000 000 ₸ включительно.
* **ПК-3.** Комиссия за перевод составляет 1 % от суммы перевода, но не меньше 200 ₸ и не больше 5 000 ₸.
* **ПК-4.** Клиент видит комиссию до подтверждения перевода; сумма перевода и комиссия списываются одной операцией.

### Требования к данным
Хранить маску номера карты получателя, сумму перевода, комиссию, время перевода по UTC+5 и идентификатор операции.

### Требования к интеграции
Приложение получает комиссию методом calcTransferFee до подтверждения перевода. Метод описан в части B.

### Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Сумма перевода 10 000 ₸ | Клиент запрашивает комиссию | Комиссия 200 ₸ |
| Сумма перевода 300 000 ₸ | Клиент запрашивает комиссию | Комиссия 3 000 ₸ |
| Сумма перевода 800 000 ₸ | Клиент запрашивает комиссию | Комиссия 5 000 ₸ |

## Часть B. REST API

### Метод calcTransferFee

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **Request URL** | `/transfers/fee` |
| **Authorization** | Bearer, сессия клиента |

#### Тело запроса

| Parameter | Format | Mandatory | Logic | Description |
| :--- | :--- | :--- | :--- | :--- |
| `cardId` | string | Да | Карта клиента | Идентификатор карты отправителя |
| `amount` | integer | Да | от 1 000 до 1 000 000 включительно | Сумма перевода в тенге |

#### Тело ответа 200

| Parameter | Format | Mandatory | Logic | Description |
| :--- | :--- | :--- | :--- | :--- |
| `fee` | integer | Да | от 200 до 5 000 включительно | Комиссия за перевод в тенге |
| `feeMinor` | integer | Да | от 20 000 до 500 000 включительно | Та же комиссия в тиынах для учётной системы |

### Статусы

| Код | Когда возвращается | Тело ответа |
| :--- | :--- | :--- |
| 200 | Комиссия рассчитана | Описано в разделе метода |
| 400 | Сумма перевода вне диапазона | `{"message":"Проверьте сумму"}` |
| 401 | Нет действующей сессии | `{"message":"Требуется вход"}` |
