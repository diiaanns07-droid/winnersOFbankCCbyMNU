# Суточный лимит снятия наличных

## Часть A. Бизнес-требования

### Функциональные требования
* **Л-1.** По умолчанию суточный лимит снятия не задан. Снятие сверх заданного лимита отклоняется с сообщением «Лимит превышен».
* **Л-2.** Использованная сумма лимита обнуляется в 00:00 по времени Астаны.

### Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Новая карта, лимит снятия не менялся | Открыть настройки лимита снятия | Суточный лимит не задан |
| Суточный лимит 50 000 ₸, за сутки снято 45 000 ₸ | Снять 10 000 ₸ | Снятие выполнено |
