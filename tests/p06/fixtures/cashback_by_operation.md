# Кэшбэк по покупкам и возвратам

## Часть A. Бизнес-требования

### Функциональные требования
* **КЭШ-1.** Для покупок расчётный месяц кэшбэка определяется по дате совершения операции по времени Астаны.
* **КЭШ-2.** Для возвратов расчётный месяц кэшбэка определяется по дате проведения операции по времени Астаны.

### Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Возврат покупки: возврат совершён 31 января в 23:58 | Провести возврат 1 февраля в 00:03 | Кэшбэк за февраль уменьшен на 10 ₸ |
