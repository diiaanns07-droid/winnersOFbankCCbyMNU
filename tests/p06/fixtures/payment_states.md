# Уведомления о платежах

## Часть A. Бизнес-требования

### Функциональные требования
* **П-1.** Для подтверждённого платежа месяц определяется по дате подтверждения по времени Астаны.
* **П-2.** Для отменённого платежа месяц определяется по дате отмены по времени Астаны.
* **П-3.** Для подтверждённого платежа клиент получает push «Платёж выполнен».
* **П-4.** Для отменённого платежа клиент получает push «Платёж отменён».

### Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Отменённый платёж: подтверждён 31 января в 23:58 | Отменить 1 февраля в 00:03 | Отмена учтена в феврале, push «Платёж отменён» |
