# Переводы между своими счетами

## Часть A. Бизнес-требования

### Функциональные требования
* **ПР-1.** Сумма перевода — от 100 до 500 000 ₸ включительно.
* **ПР-2.** Минимальная комиссия — 1 ₸.

### Требования к данным
Минимальная комиссия хранится как 100 тиын.

## Часть B. REST API

### Общие параметры

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **Request URL** | `/transfers/create` |

### Параметры запроса

| Parameter | Format | Mandatory | Logic | Description | DB field |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `amount` | integer | Да | 100–300 000 | Сумма перевода в тенге | `amount_kzt` |
| `fee` | integer | Нет | 1–1 000 | Минимальная комиссия в тенге | `fee_min_kzt` |

### Ответ

| Parameter | Format | Logic | Description | DB field |
| :--- | :--- | :--- | :--- | :--- |
| `result` | string | OK / ERROR | Исход перевода | — |
| `amount` | string | Строковое представление числа, например «50000» | Сумма перевода в тенге | `amount_kzt` |

### Статусы

**200.** Ответ в случае успешного выполнения метода.  
**401.** Ответ в случае, если не передан токен.

#### 200. Successful
```json
{"result":"ERROR","message":"Карта заблокирована"}
```

#### 401. Unauthorized
```json
{"message":"Требуется вход"}
```
