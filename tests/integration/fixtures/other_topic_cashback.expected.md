# Засеянные дефекты: other_topic_cashback.md

Эталон команды для сверки находок на документе другой тематики (кэшбэк). Номера строк — по файлу.

| # | Серьёзность | Дефект | Строки |
| :--- | :--- | :--- | :--- |
| D1 | критичное | КБ-1 (выбор только с 1 по 5 число) противоречит КБ-4 (менять в любой момент) и строке 2 приёмки (замена 10 числа) | 19, 22, 39 |
| D2 | критичное | Строка 3 приёмки: 9 800 ₸ + 5 % от 10 000 ₸ = 500 ₸ превышает месячный лимит 10 000 ₸ из КБ-2 (ожидалось 200 ₸) | 20, 40 |
| D3 | критичное | Чтение категорий обещано («получает и меняет»), в API только метод сохранения | 32, 52 |
| D4 | существенное | GET для изменения данных (`setCategories`) | 51–52 |
| D5 | существенное | `categories`: array в запросе, string в ответе | 59, 65 |
| D6 | существенное | Пример ответа 200 содержит ERROR, хотя 400 — неверные параметры | 70–75 |
| D7 | существенное | Кэшбэк в тиынах, лимит в тенге без правила пересчёта и округления | 29 |
| D8 | существенное | «2 рабочих дня» и «календарный месяц» без календаря и часового пояса | 19, 21 |
| D9 | существенное | КБ-5: открытый перечень «и т. д.»; не описан частичный возврат и возврат в другом месяце | 23 |
| D10 | незначительное | НФТ «быстро и удобно» непроверяемо; цель «быстро видит» | 16, 26 |
| D11 | незначительное | Нет ID у НФТ, данных, интеграции; приёмка не ссылается на ID требований | 26, 29, 32, 38–40 |
