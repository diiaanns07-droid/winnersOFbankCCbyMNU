## Для №01 и интегратора №11 до выхода тега

Проверены исходные карточки `findings_before` официального ТЗ на влитом коде `2eac95cb`, до применения ответов владельца. Один полный запуск Sonnet. Ниже только воспроизводимые ошибки в содержании. Номера D принадлежат этому запуску и могут измениться в отчёте жюри. [Исходные карточки в паспорте F4](answers_exam/merged/official/answered.json) · [ТЗ с номерами строк](https://github.com/diiaanns07-droid/winnersOFbankCCbyMNU/blob/2eac95cb/release/input/requirements.md).

| Карточка | Что исправить и как проверить |
| --- | --- |
| D-10, доступ по дополнительной карте | Для вошедшего пользователя сценарий обещает 401 или 404. В ТЗ 401 относится к отсутствию авторизации (стр. 174). Оставить настоящий вопрос, кто вправе настраивать карту, и убрать 401 из этого примера. |
| D-11, возврат и повторный push | В примере одна карта, тот же месяц, порог не менялся, сообщение уже отправлено. Ф-3 допускает максимум одно сообщение (стр. 39). Убрать нерешённый выбор «посылать второй» для этого примера. Отдельно проверить возврат, затрагивающий закрытый месяц. |
| D-13, повтор события | У одной повторной доставки сценарий допускает повторное сложение полной суммы. Стр. 52 прямо требует сохранить исходный итог. Для неясной области ключа нужен иной пример, а для сбоя между учётом и отправкой — пример с конкретным моментом отказа. |
| D-21, форма ошибки | В готовую правку внесено `result <уточнить: тип>`, хотя тип string определён на стр. 155. Неизвестна обязательность поля для конкретных кодов. Сохранить объявленный тип и запросить только это решение. |
| D-25, срок передачи push | Карточка утверждает, что точка измерения отсутствует. Стр. 46 задаёт начало «после получения события» и конец «передаёт push на отправку». Исправить описание пробела и сохранить вопрос о расчётной нагрузке. |
| D-26, критерии приёмки | В рекомендации предложение оборвано открытой скобкой «(см.» перед новой фразой. Поиск по полю `recommendation` находит его буквально. Указать конкретные пропущенные строки приёмки и завершить предложение. |

В этом исходном прогоне были пять критичных карточек.
