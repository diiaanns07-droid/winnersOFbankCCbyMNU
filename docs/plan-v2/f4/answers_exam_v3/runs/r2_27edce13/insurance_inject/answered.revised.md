### Цели
Клиент может добровольно подключить страхование жизни при оформлении кредита наличными и получить ставку ниже, а в период охлаждения — отказаться от страхования в приложении. Увеличить долю кредитов со страхованием без жалоб на навязывание услуги.

### Архитектура решения
Мобильное приложение → API кредитов → кредитный конвейер. Кредитный конвейер → сервис страхования → страховая компания-партнёр. Сервис страхования → сервис уведомлений.

### Дизайн процесса UI
Кредиты → «Кредит наличными» → экран условий: сумма, срок, флажок «Страхование жизни» (по умолчанию снят), стоимость страхования, ставка со страхованием и без него, ссылка на правила страхования и согласие на передачу ИИН, ФИО, даты рождения и номера телефона страховой компании-партнёру. [изменено: D-11]
После выдачи: Кредиты → кредит → «Страхование» → номер полиса, дата начала действия и кнопка «Отказаться от страхования».

### Требования к изменениям

#### BPMN схема процесса
Выбор условий кредита → подключение страхования по желанию клиента → расчёт премии → подписание договора кредита и заявления на страхование → выдача кредита и оплата премии → выпуск полиса → отказ в период охлаждения и возврат премии (если клиент отказался) → завершение.

#### Функциональные требования
* **Ф-1.** Страхование предлагается при оформлении кредита наличными от 300 000 до 5 000 000 ₸ на срок от 6 до 60 месяцев. Подключение добровольное: флажок по умолчанию снят, отказ от страхования не влияет на одобрение кредита.
* **Ф-2.** Страховая премия равна сумме кредита × 0,15 % × срок кредита в месяцах. Премия оплачивается единовременно из суммы кредита при выдаче, страховая сумма равна сумме кредита.
* **Ф-3.** Ставка по кредиту со страхованием — 24 % годовых, без страхования — 27 % годовых.
* **Ф-4.** Клиент может отказаться от страхования в течение 14 календарных дней с даты выдачи кредита; последний день для отказа — 14-й календарный день до 23:59 по времени Астаны; сумма возврата премии — <уточнить: вся премия или с удержанием, в какой доле>; возврат выполняется на текущий счёт клиента в течение 7 рабочих дней. После отказа ставка по кредиту повышается до 27 % годовых со дня отказа. По истечении 14 дней кнопка «Отказаться от страхования» недоступна. [изменено: D-02, D-03]
* **Ф-5.** При полном досрочном погашении кредита страхование прекращается, клиенту возвращается часть премии за полные неиспользованные месяцы.
* **Ф-6.** Страхование доступно клиенту от 18 лет, которому на дату окончания кредита будет не больше 65 лет.

1. Проверить сессию клиента.
2. Проверить, что заявка на кредит принадлежит клиенту и ещё не подписана.
3. Проверить сумму кредита (300 000 – 5 000 000 ₸) и срок `term` (6–60).
4. Проверить возраст клиента на дату окончания кредита. 5. Рассчитать премию по Ф-2 и ставку со страхованием.
6. Передать данные клиента в СК для предварительной проверки, сохранить подключение страхования в заявке и вернуть результат. ### Особые правила
1. Повторный вызов с теми же суммой и сроком возвращает действующие условия страхования.
2. Если клиент изменил сумму или срок после подключения, приложение вызывает метод повторно, и условия страхования пересчитываются.
3. Отказ от страхования не изменяет условия кредитного договора.
4. Приложение вызывает метод только после того, как клиент дал на экране условий согласие на передачу ИИН, ФИО, даты рождения и номера телефона страховой компании-партнёру. Факт согласия хранится: <уточнить: где хранить факт согласия>. [добавлено: D-11]

* 3. Вернуть номер полиса, дату начала действия, премию и дату, до которой доступен отказ; пока полис не выпущен, номер полиса и дата начала действия не возвращаются. [добавлено: D-01]
#### Параметры запроса метода получения данных полиса [добавлено: D-01]

| Parameter | Format | Size | Mandatory | Logic | Description | DB field [добавлено: D-01] |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| applicationId | string | 1–64 | Да | Заявка клиента | Идентификатор заявки на кредит | application_id [добавлено: D-01] |
#### Ответ метода получения данных полиса [добавлено: D-01]

| Parameter | Format | Logic | Description | DB field [добавлено: D-01] |
| :--- | :--- | :--- | :--- | :--- |
| status | string | CONNECTED / CANCELLED | Состояние страхования | insurance_status [добавлено: D-01] |
| policyNumber | string | После выпуска полиса | Номер полиса | policy_number [добавлено: D-01] |
| startDate | string | После выпуска полиса | Дата начала действия | — [добавлено: D-01] |
| premium | integer | Всегда | Страховая премия, ₸ | premium_kzt [добавлено: D-01] |
| cancellationAvailableUntil | string | После выдачи кредита, пока отказ доступен | Последний день отказа | — [добавлено: D-01] |
#### Статусы метода получения данных полиса [добавлено: D-01]
* 200. Данные страхования возвращены. [добавлено: D-01]
* 401. Запрос выполнен без необходимой авторизации. [добавлено: D-01]
* 404. Заявка не найдена, принадлежит другому клиенту или страхование по ней не подключено. [добавлено: D-01]
* 500. Внутренняя ошибка сервера. [добавлено: D-01]
200. Successful [добавлено: D-01]
