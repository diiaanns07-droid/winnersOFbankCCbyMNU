### Цели
Клиент заранее видит, до какой даты и какую сумму нужно внести, чтобы не платить проценты за покупки по кредитной карте. Снизить долю клиентов, которые теряют льготный период из-за пропущенной даты платежа.

### Архитектура решения
Мобильное приложение → API кредитных карт → кредитный модуль. Кредитный модуль → сервис уведомлений → push-уведомление клиенту.

### Дизайн процесса UI
Главная → Кредитная карта → блок «Льготный период». В блоке показаны дата окончания платёжного периода, сумма для погашения без процентов, сколько календарных дней осталось (день окончания не считается), кнопка «Пополнить» и переключатель «Напоминать о платеже». Если льготный период утрачен, вместо даты показывается надпись «Начисляются проценты» и общая сумма задолженности. [изменено: D-06]
Суммы на экране показываются в тенге с тиынами, например: 30 000,00 ₸. [добавлено: Решение-2]

### Требования к изменениям

#### BPMN схема процесса
Формирование выписки → расчёт суммы для погашения → ожидание платежа → напоминание за 3 дня → проверка погашения в конце платёжного периода → сохранение или утрата льготного периода.

#### Функциональные требования
* **Ф-1.** Льготный период действует для покупок по кредитной карте и длится до 55 календарных дней. Расчётный период равен календарному месяцу, выписка формируется 1-го числа следующего месяца, платёжный период заканчивается 25-го числа того же месяца. Если 25-е число приходится на нерабочий день, окончание платёжного периода переносится на ближайший следующий рабочий день. [изменено: D-05]
* **Ф-2.** Сумма для погашения без процентов равна задолженности по покупкам расчётного периода на дату выписки. Покупка относится к расчётному периоду по дате её отражения на счёте карты. Снятие наличных и переводы с кредитной карты в льготный период не входят: проценты по ним начисляются с даты операции. Платежи за услуги, пополнение электронных кошельков и комиссии банка: <уточнить: входят ли в сумму для погашения или проценты начисляются с даты операции>. [изменено: D-08]
* **Ф-3.** Если клиент внёс сумму для погашения полностью до окончания платёжного периода включительно (платёж считается внесённым в момент <уточнить: создание платежа клиентом или зачисление на счёт карты>; платёжный период заканчивается в <уточнить: час и часовой пояс> последнего дня), проценты по покупкам расчётного периода не начисляются. Если внесено меньше, проценты начисляются на всю задолженность по покупкам расчётного периода с даты каждой покупки. [изменено: D-05]
* **Ф-4.** Если переключатель «Напоминать о платеже» включён и сумма для погашения не внесена полностью, за 3 календарных дня до окончания платёжного периода (с учётом переноса по Ф-1) клиент получает в 10:00 по времени Астаны push с датой окончания и оставшейся суммой. По умолчанию переключатель включён. [изменено: D-05, Решение-1]
* **Ф-5.** Внесённый платёж уменьшает оставшуюся сумму для погашения. Возврат покупки, отражённый до окончания платёжного периода, тоже уменьшает оставшуюся сумму. Покупки, отражённые на счёте после даты выписки, относятся к следующему расчётному периоду и сумму для погашения не меняют.
* Ф-6. Напоминание о платеже входит в состав поставки. [добавлено: Решение-3]

### Логика работы метода
1. Проверить сессию клиента.
2. Проверить, что карта принадлежит клиенту (иначе вернуть 404). Если карта не кредитная, перейти к шагу 6. [изменено: D-02]
3. Получить из кредитного модуля последнюю выписку, платежи и возвраты покупок после даты выписки, а также общую задолженность по карте на дату запроса и покупки после даты выписки. [изменено: D-09]
4. Рассчитать оставшуюся сумму для погашения как сумму из выписки за вычетом платежей и возвратов покупок, отражённых до окончания платёжного периода, и количество календарных дней до окончания платёжного периода. [изменено: D-09]
5. Вернуть сведения о льготном периоде и прогноз процентов на случай частичного погашения.
6. Если карта не кредитная, вернуть 200 с status = NOT_APPLICABLE и пустыми суммами. [изменено: D-02]

### Особые правила
1. Сумма для погашения не может быть отрицательной: переплата показывается как 0.
2. При частичном погашении прогноз процентов считается на всю задолженность по покупкам расчётного периода с даты каждой покупки. [изменено: D-04]
3. Если выписка ещё не сформирована, возвращаются сведения по предыдущему платёжному периоду.
