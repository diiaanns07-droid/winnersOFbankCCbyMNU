# Переносимость команд из паспорта

В Windows на чистой интеграции `3e7133c2`, Python 3.12 и зависимостях из `requirements.txt` полный набор `tests/v2` дал 2204 пройденных теста и один сбой. Ещё пять пропущены, три ожидаемо упали, семь помеченных ожидаемыми падениями прошли. Сбой воспроизводится в тесте команды `verify` из паспорта. Абсолютный путь Linux сохранялся целиком при составлении отчёта под Windows. Кроме того, путь к JSON с пробелами печатался без кавычек, и при копировании команды одна папка превращалась в несколько аргументов. [Тест релизной версии](https://github.com/diiaanns07-droid/winnersOFbankCCbyMNU/blob/3e7133c2/tests/v2/test_33_report.py#L139) · [Исправление и регрессии](passport-paths.patch).

Правка сохраняет относительные каталоги, сокращает абсолютные пути POSIX, Windows и UNC до имени файла и заключает относительные пути с пробелами в кавычки. При целевой проверке прошли 109 тестов формирования и проверки отчёта. Существующий тест сохранён. Новые случаи включают два стиля абсолютного пути, сетевой ресурс и относительное имя с пробелами. [Изменение кода с проверками](passport-paths.patch).

В отдельной чистой рабочей копии интеграционной версии:

```powershell
git apply --check "$f4/acceptance/passport-paths.patch"
git apply "$f4/acceptance/passport-paths.patch"
python -m pytest tests/v2/test_33_report.py tests/v2/test_13_report.py tests/v2/test_13_verify.py tests/v2/test_33_verify.py -q
```
