## Повторить проверку выпуска

Задайте `$f4` как абсолютный путь к `docs/plan-v2/f4` в аудиторской ветке. В рабочей копии `3e7133c2` установите зависимости проекта. Пара длинных команд ниже делает измерение локально. Для браузера укажите установленный Chrome или Edge через `--browser` либо предварительно установите Chromium командой `python -m playwright install chromium`. Путь `$f4` используется также в [командах опыта с форматами](formats.md).

```powershell
python -m pip install -r requirements.txt -e .
powershell -ExecutionPolicy Bypass -File scripts/jury_check.ps1 mock
python "$f4/acceptance/runtime.py" --repo . --out out/f4-runtime
python -m pip install playwright
python "$f4/acceptance/browser_answers.py" --repo . --report out/jury/requirements.mock.html --out out/f4-browser --browser "C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe"
python -m pytest tests/v2 -q
```

Рекламные обещания о лидерстве требуют общего независимого корпуса и отчётов второй системы. Здесь опубликованы собственные измерения BCC Review. [Ограничения и слепой протокол](../blind-protocol.md).
