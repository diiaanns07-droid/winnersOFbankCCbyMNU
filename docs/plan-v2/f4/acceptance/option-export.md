# Сохранить смысл ответа при перестановке вариантов

На одном реальном вопросе автокредита проверены три варианта следующего вопросника и три ширины браузера. В исходном HTML смысл выбора A сохранился в **3 из 9** проверок. После правки — в **9 из 9**. Это девять технических проверок одного выбора, по три для каждого условия. [Результаты с точными текстами](option-export-results.json) · [Реальная ошибка на пятидневной границе](owner-e2e/RESULTS.md).

| Следующий вопросник | До правки | После правки |
|---|---:|---:|
| Тот же вопрос и те же ответы | 3/3 | 3/3 |
| Те же ответы в обратном порядке | 0/3 | 3/3 |
| Вопрос и варианты заново сформулированы в другом полном запуске Sonnet | 0/3 | 3/3 |

В исходном отчёте A разрешал подать заявку ровно за пять дней до взноса. В независимо сформированном вопросе A требовал отказ. Браузер раньше записывал в скачанный файл только букву. В новой версии он записывает и текст показанного варианта. Если следующий вопрос содержит тот же текст в другой позиции, обработчик находит его. Если варианты переформулированы, обработчик сохраняет буквальное решение человека. Так исходная цифра и условие переходят в пересмотр без повторного угадывания.

Проверка выполнена через реальную кнопку скачивания в Edge при ширине 1440, 768 и 390 пикселей. Полученный Markdown обработан штатными функциями чтения и привязки. Старая текстовая форма `Q-01: A` по-прежнему работает. Для старого файла, содержащего только букву, восстановление смысла требует вопросника, показанного владельцу. Правка действует при следующей выгрузке из обновлённого HTML. В группах тестов редактора, HTML и пересмотра прошло 239 проверок. [Правка и две регрессии](owner-option-text.patch) · [Испытание в браузере](option_export.py).

В чистой копии `d013c123` установите Playwright и Chromium. Задайте `$f4` как путь к каталогу аудита и выполните команды. Первая проверка заканчивается кодом 1 и сохраняет три верных прочтения, вторая — кодом 0 и сохраняет девять.

```powershell
python -m pip install playwright
python -m playwright install chromium
python "$f4/acceptance/option_export.py" --repo . --evidence "$f4" --out out/f4-choice-before
git apply "$f4/acceptance/owner-option-text.patch"
python "$f4/acceptance/option_export.py" --repo . --evidence "$f4" --out out/f4-choice-after
python -m pytest tests/v2/test_11_f4_answers.py tests/v2/test_11_recheck.py tests/v2/test_13_report.py -q
```
