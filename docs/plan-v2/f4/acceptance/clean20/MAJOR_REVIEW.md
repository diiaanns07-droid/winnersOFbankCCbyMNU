# Ручная оценка всех 31 major на восьми ТЗ

Из 31 существенной карточки F4 оставляет **8 major**, понижает **18 до minor**, предлагает снять **5**. Эти оценки одного разметчика показывают, почему пустой авторский ключ нельзя принимать за независимый факт отсутствия любых недочётов. В частности, не указан срок возврата части страховой премии при полном досрочном погашении и не определён исход для клиента после последней попытки заказать выписку без ответа. [Сводка и пять critical](README.md) · [Разметка для пересчёта](major-review.json).
