# Живой судья на обновлённом релизном коде

На чистой интеграции `d013c123` повторена проверка восьми открытых ТЗ. В четырёх исправленных документах объявлены 1 critical и 17 major. Ручная проверка нашла 1 завышенный critical. В четырёх исходных парах найдены 16/16 блокирующих и 20/20 существенных эталонных причин. Уровень critical получили 14/16 блокирующих причин. Один прогон этапа судьи на документ, фактическая модель `claude-haiku-5-5`, без кеша и без резервной модели. [Сводка и изменения по каждой причине](release/summary.json).

Для каждого документа совпали SHA исходника, требования и весь список проверенных кандидатов, который получает судья. Сравнивались значения полей каждого кандидата, включая обе стороны цитат и их порядок. В служебных сигналах этапа правил зафиксировано различие в 3 из восьми документов. Такие сигналы не включаются в вызов судьи. Например, для страхования у S-04 поменялась строка вспомогательной опоры. Этот опыт проверяет этап судьи на сохранённых входах. Для живого запуска всех этапов документа нужен отдельный замер. Это единственный ложный запрет на этих четырёх документах. [Базовая проверка тех же причин](integration_review.md).
