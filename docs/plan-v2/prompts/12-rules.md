## Твоя роль: №12 — детерминированные правила v2 и офлайн-режим. Ветка: `v2/12-rules`

Правила v1 — урок: 179 замечаний, 0 попаданий, 44 ложные тревоги на 8 чистых ТЗ, 64 замечания «нет ID». В v2 правила дают сигналы высокой точности для линз и кандидатов для судьи, а не готовые замечания.

**Твои файлы:** `src/bcc_review/v2/rules/*.py`, `tests/v2/test_12_*`.

Интерфейс: `rules.run(view, requirements=None) -> {"signals": [...], "candidates": [...]}` (CONTRACT, раздел 3); кандидат — схема 2.3 с `source` вида `rules:<id>`.

**Детекторы** (общие для любых банковских ТЗ, без слов официального документа в коде):
1. Язык (29148, п. 5.2.7): словари размытых и субъективных слов, лазеек, открытых перечней («и т. д.», «и далее», «и прочее»), неизмеримых сравнений — только в строках-обязательствах, не в названиях и примерах. Это сигнал, а не кандидат; кандидат — только открытый перечень в перечислении правил.
2. Заглушки: «—», «TBD», «заполняются …», пустые обязательные поля, неотмеченные «Да / Нет» в чек-листе, пустой блок согласующих, нет версии или даты — по одному minor-кандидату на документ на каждый вид.
3. API: GET/HEAD при глаголе изменения в пути или описании (save, update, set, delete, create; «сохранение», «изменение»); Content-Type при «тело не используется»; код ответа упомянут в тексте или логике, но раздела для него нет; заголовок раздела с одним кодом, а текст с другим; одно поле с разными типами в запросе и ответе; «и далее» в перечне кодов.
4. Единицы: одна величина в разных единицах (минорные и мажорные единицы валюты, секунды и минуты, час и сутки, UTC и местное время) — по связке «поле/величина + единица».
5. Обещания без реализации: глаголы чтения и отображения («читает», «показывает», «получает») при дочерней спецификации без операции чтения — сигнал для №07.

Отдельно — офлайн-режим `--provider offline` (модели нет): короткий отчёт «Предварительная проверка без модели» — только сигналы и кандидаты правил, вердикт «не определено» с объяснением; никогда «можно начинать»; «нельзя» — только если правило нашло конфликт с двумя цитатами об одном предмете.
