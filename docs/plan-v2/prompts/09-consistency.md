## Твоя роль: №09 — проверка набора требований целиком. Ветка: `v2/09-consistency`

ТЗ требует отдельно проверить набор: согласованность, полноту, покрытие, прослеживаемость. В v1 этот этап на живой модели вернул 0 кандидатов на документе с явным конфликтом и выдал ложный конфликт между двумя разными полями. Ключ к успеху — сравнивать только одно и то же: тот же параметр, то же событие, тот же момент.

**Твои файлы:** `src/bcc_review/v2/stages/consistency.py`, `src/bcc_review/v2/prompts/consistency.md`, `tests/v2/test_09_*`.

Схема ответа: `candidates` + `pair_checks` + `trace` + `glossary` (CONTRACT 2.3, 2.5).

**Что делает этап:**
1. `pair_checks` (до 15, сначала самые рискованные). Найди все предметы — поле, параметр, событие, состояние, величину, счётчик, — которые регулирует больше одного места (требования, цель, особые правила, логика API, части документа). Для каждой пары по порядку: `subject` (назови предмет и значение) → `same_subject` (предметы разные — пару не сравнивать) → дословные цитаты обеих сторон → сценарий, где применимы обе (исходное состояние, события по порядку, даты и числа; ищи исключения и усилители «независимо от», «не более», «только», смену настроек посреди периода, повтор, границу периода) → исход по A → исход по B → verdict. Критерии приёмки здесь не сверяй — это делает №06.
   Код: `conflict` → critical-кандидат (event_conflict, status_conflict, boundary_conflict или unit_mismatch по смыслу) с двумя цитатами; `undefined` → major.
2. Цель документа против требований и НФТ.
3. `glossary`: одно понятие — разные названия (участники, компоненты, сущности), с номерами строк; дефект `terminology`, если разночтение влияет на реализацию.
4. Полнота набора: какие сценарии бизнес-процесса не покрыты ни одним требованием.
5. `trace`: для каждого функционального и нефункционального требования — какие критерии приёмки его проверяют и какие пункты API или данных реализуют; `note` — чего не хватает. Код строит матрицу покрытия для отчёта.
6. Ранжирование, модифицируемость (одно правило записано в двух местах), прослеживаемость (ID, источник).
