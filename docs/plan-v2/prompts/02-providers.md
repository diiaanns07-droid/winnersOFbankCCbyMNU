## Твоя роль: №02 — провайдеры LLM. Ветка: `v2/02-providers`

Жюри почти наверняка запустит агента одной командой на бесплатном ключе Gemini. В v1 это ломалось: `gemini-2.5-flash` → 404, `gemini-3.8-flash` → 503 при перегрузке, Claude API → 400 из-за лишнего поля `cache` в сообщении. Твоя задача — чтобы модель отвечала всегда, а если не может, отчёт честно об этом говорил.

**Твои файлы:** `src/bcc_review/v2/providers/{claude_cli,gemini,anthropic_api,openai_compat,doctor}.py`, `tests/v2/test_02_*`.

Интерфейс провайдера — CONTRACT.md, раздел 3 (тот же `invoke`, что у адаптеров v1). В `messages` только `role` и `content`.

**Задачи:**
1. **claude_cli** (прототип `docs/plan-v2/ref/claude_cli_adapter.py`; №01 положит его в скелет, дальше файл твой): `claude -p --output-format json --tools "" --model M --json-schema S --system-prompt SYS`, текст через stdin; разбор `structured_output`, `usage`, `total_cost_usd`, фактической модели из `modelUsage`; ошибки → `ProviderError` с `kind` (rate_limit/overloaded — повторяемые); таймаут; переменные `CLAUDE_CLI_MODEL`, `CLAUDE_CLI_EFFORT`; на Windows — `claude.cmd`. Проверь живьём на маленькой схеме и на одном этапе официального документа.
2. **gemini**: обёртка над v1 `bcc_review.providers.gemini` (там 137 тестов) или новый компактный адаптер на `google-genai` — реши за 20 минут чтения кода. Требования: модель по умолчанию `gemini-3.8-flash`; цепочка отката `GEMINI_FALLBACK_MODELS`, по умолчанию `gemini-3.6-flash,gemini-3.5-flash-lite`; на 503/504/overloaded — 3 повтора с паузой 2/5/10 с, затем следующая модель; на 404 — сразу следующая; на 429 — ждать Retry-After; structured output через `response_json_schema` (или `response_schema`) с санитайзером схемы под ограничения Gemini; `max_output_tokens` 32 000; thinking — умеренный бюджет. Фактическая модель пишется в паспорт.
3. **anthropic_api**: обёртка над v1-адаптером или новый на SDK `anthropic`; без поля `cache` в messages; кэширование промпта через `cache_control` на system и блоке документа; structured outputs.
4. **openai_compat**: `OPENAI_BASE_URL` + `OPENAI_MODEL` (+ `OPENAI_API_KEY` по желанию) для Ollama, vLLM, LM Studio, OpenRouter — это «закрытый контур» банка для защиты; `response_format` json_schema, откат на json_object с проверкой схемы.
5. Выбор `auto` (CONTRACT, раздел 3) и понятные русские ошибки без трейсбэка: нет ключа, неверный ключ, квота, модель недоступна — с советом, что сделать.
6. **doctor**: `python -m bcc_review doctor [--live]` — версия Python, зависимости, какие ключи заданы (значения не печатать), доступные модели Gemini (`models.list`), есть ли `claude`; с `--live` — пробный вызов с коротким JSON у выбранного провайдера.
7. Тесты без сети: фейковые клиенты на каждый тип ошибки и на откат модели; записанные ответы.

Если в окружении сессии появится доступ к Gemini (оператор может добавить ключ в Network secrets окружения для `generativelanguage.googleapis.com`), проверь живьём: `python -m bcc_review doctor --live --provider gemini` и полный прогон официального документа; время, вызовы и фактическую модель — в статус. Если ключа нет — подготовь для GPT Pro (№17) и оператора точную команду проверки на Windows и запиши её в статус.

**Готово, когда:** на фейках проходит каждая ветка ошибок; claude_cli прогнал этап живьём; Gemini проверен живьём или есть готовая команда проверки; doctor понятен новичку.
