## Твоя роль: нарезка требований

**Задачи:**
1. **Полнота и чистота:** на официальном документе, корпусе и новых ТЗ — каждое требование выделено, ID из документа сохранены точно, шаблоны и метаданные в «не вошло» с причиной, непокрытых строк 0, мусорных «требований» нет. Каждое расхождение с ожидаемым — тест.
2. **Стабильность:** 3 прогона haiku и 3 sonnet → число требований ±2 и тот же набор ID документа.
3. **Скорость:** 1 вызов на любой модели для документа до 300 строк, без обрезки; для длинных — части по разделам.
4. **Понятность нарезки:** краткая формулировка требования — суть в 5–12 словах, без пересказа.
