Ты — сессия Claude Code команды STUPITS (хакатон BCC-HUB × MNU, кейс «ИИ-агент проверки требований»), роль №38.
Если раньше ты был другим номером — твоя прежняя ветка и статус остаются, это новая короткая задача: у тебя мало
лимита, поэтому коммить и пушь каждые 5 минут, а итог — не позже чем через 45 минут.
Репозиторий: https://github.com/diiaanns07-droid/winnersOFbankCCbyMNU. Всё по-русски.

## Задача
Пройди путь члена жюри строго по `README.md` и `SUBMISSION.md` ветки `bcc/v2` (после 21:00 — ветки `release`), как
будто видишь проект впервые, и запиши каждое место, где он споткнётся.
1. Свежий клон во временный каталог; новое виртуальное окружение; `pip install -r requirements.txt` — время установки.
2. Шаги README по порядку: `python -m bcc_review doctor`; прогон без ключа
   (`python -m bcc_review release/input/requirements.md out/mock.md --provider mock`); `verify`; открыть HTML-отчёт
   (скриншот через Playwright, ширина 1440 и 390); `scripts/jury_check.sh` в режиме без ключа, если он есть.
3. Команды для Windows (PowerShell) — прочитай и проверь синтаксис глазами: кавычки, пути с `\`, `-ExecutionPolicy`.
4. Все ссылки README и SUBMISSION — открываются ли (чего нет — список).
5. **Итог** — `docs/plan-v2/status/38.md` в ветке `v2/38-jury5`: пронумерованный список «шаг → что написано в README →
   что произошло → как поправить», сначала то, что остановит жюри. Опечатки и битые ссылки — готовой правкой
   (патч в `tests/v2/fixtures/38_patches/`) для №36: README и SUBMISSION ведёт он.

## Правила
- Только чтение и свой статус; код продукта не трогать. Живые вызовы модели не нужны.
- В статусе строка «Остановился на: … Следующий шаг: …» — если лимит кончится, другой чат продолжит.
- Отчёт владельцу — 3–5 строк: сколько заняли первые 5 минут, что остановит жюри, где патч.
