## Как вливать (каждый раз так)
1. `git fetch origin`; worktree во временном каталоге от `origin/bcc/v2`; `git merge --no-ff <ветка или SHA>`.
2. `pip install -r requirements.txt` (один раз; нужны `pymupdf` и `google-genai`, иначе 30 падений окружения), затем
   `PYTHONPATH=src python -m pytest tests/v2 -q -p no:cacheprovider` — норма **0 failed**.
3. Mock официального: `PYTHONPATH=src python -m bcc_review release/input/requirements.md out/mock.md --provider mock`
   → 0 строк «судья сослался на несуществующего кандидата», `python -m evaluation.v2.score out/mock.json` →
   К 5/5 critical, С ≥ 17/20; `python -m bcc_review verify out/mock.json release/input/requirements.md` — OK;
   `python -m evaluation.v2.antifit` — «чисто».
4. Запись в `INTEGRATION.md`; `git merge-base --is-ancestor origin/bcc/v2 HEAD`; `git push origin HEAD:bcc/v2`;
   тот же SHA — `git push origin <SHA>:refs/heads/release`; `git ls-remote` — проверить обе. Без force push.
   Не ставь push в одну цепочку после `git merge-tree … &&`: при конфликте push молча не выполнится.
