1. Новый временный каталог (не тот, где уже лежит репозиторий). `git clone -b release <url> bcc-review`.

2. Python: какая версия стоит (`py -0p` на Windows, `python3 --version` на macOS). Новое виртуальное окружение,
   `pip install -r requirements.txt` — время установки.
3. Шаги README по порядку: `python -m bcc_review doctor`; прогон без ключа
   `python -m bcc_review release/input/requirements.md out/mock.md --provider mock`; `python -m bcc_review verify
   out/mock.json release/input/requirements.md`; открыть `out/mock.html` в браузере; веб `python -m
   bcc_review.v2.web --open` — открылся ли браузер, что на экране. На Windows — в PowerShell, как написано в README:
   кавычки, `\` в путях, `-ExecutionPolicy`, кодировка вывода (кракозябры в консоли — находка).
