## Задача
1. **Прогресс** (раздел 8.3): BCC AI 96 px (`<div data-bcc-agent data-size="96" data-mood="scanning">`, режим меняй

   `alert`, если есть блокеры; API — в `wave5/README.md`, делает №40, до его вливания плитка пустая). Этапы списком
   на бумаге: выполненный — зелёная галочка, текущий — мягко пульсирующая точка, ожидающий — тихий. Время и вызовы
   модели — одной строкой. Ошибка прогона — одна строка `.b-status.error` и «что сделать».
2. **Отчёт** (раздел 8.4): сверху крупно вердикт («Разработка: нельзя · Тестирование: нельзя»; цвет — по смыслу) и

   списком (одна поверхность, строки через тонкую линию: номер D-01, суть, где в документе); вкладки-капсулы
   «Замечания · Вопросы · Документ · Исправленная редакция · Выгрузки»; щелчок по замечанию — боковое стеклянное
   окно с документом и подсвеченными строками (подсветка уже есть — сделай её красивой и плавной). Фильтры
   замечаний по критичности — сегментом.
3. **`report.css`** — HTML-отчёт CLI на токенах `bcc-ui.md` (значения внутри файла: отчёт открывают и без сервера);
