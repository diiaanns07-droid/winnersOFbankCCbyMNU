## А. BCC AI в терминале (делают №40 и №42; остальным — для сведения)

**№40, к 20:45 — `src/bcc_review/v2/web/tty_agent.py`** (без зависимостей):
- Тот же дрон, что в `agent.js`: спрайт 80×80 из `docs/design/source/stupits-title-slide.html` (`makeDrone`, `DSK`),
  уменьшенный до ~40×40 и выведенный полублоками `▀` с цветом переднего и заднего плана: 24-битный цвет, если
  терминал умеет (`COLORTERM=truecolor`, Windows Terminal), иначе 256 цветов, иначе маленький ASCII-дрон. На
  Windows включить VT-режим консоли (`SetConsoleMode` с `ENABLE_VIRTUAL_TERMINAL_PROCESSING` через `ctypes`), вывод
  в UTF-8. Ширина терминала < 60 — уменьшить, не ломать строки.
- Короткая жизнь, 1–1.5 с: дрон моргает и смотрит в сторону реплики; реплика печатается по буквам. Без мерцания:
  курсор в начало блока, перерисовка на месте.
- Реплики (на «вы», коротко): «Здравствуйте! Я BCC AI — проверяю ТЗ до начала разработки.» → «Вставьте ключ Gemini
  (бесплатно, за минуту: https://aistudio.google.com/apikey) или Claude. Enter — без ключа.» Ввод скрыт
  (`getpass`). Провайдер — по началу ключа (`AIza…` → Gemini, `sk-ant-…` → Claude). Проверка тем же кодом, что
  `doctor --live` (не дольше 10 с), дрон в режиме `analyzing` со спиннером. Успех — `verified` и «Ключ работает.
  Запомнить на этом компьютере? [Д/н]» → строка в `.env` (как `/api/key`). Ошибка — `alert`, одна строка причины и
  повторный ввод; Enter — без ключа. Ключ нигде не печатается.
- Ключ уже есть (`.env`, окружение или Claude Code CLI) — дрон 1 с: «С возвращением! Ключ на месте — открываю
  систему.» Нет терминала (`not sys.stdin.isatty()`), `--check`, `--no-tty`, CI — ничего не спрашивать.
- API: `greet(port: int, env_path: Path) -> str` (возвращает выбранного провайдера). Тест без сети и без TTY.

**№42, к 21:00:** `main()` зовёт `tty_agent.greet(...)` перед открытием браузера (до вливания №40 — заглушка через
`try/except ImportError`); журнал запросов `GET /assets/… 200` в консоль не выводить (только ошибки и предупреждения —
переопределить `log_message`); после реплики — одна строка «Система открыта: http://127.0.0.1:8014 · остановить —
Ctrl+C». Браузер открывается на главной, а не на веб-знакомстве, если ключ уже введён в терминале. Снимок терминала
(`42-terminal.png`) — заново: Windows Terminal или xterm-256color, ширина 100.

## Б. Сайт — «не ИИ-слоп» (№39, №40, №41, №43; каждый в своих файлах)

Слоп — это шаблон без содержания: размытые цветные пятна по углам, большой заголовок-лозунг, пустая зона загрузки по
центру, семь кнопок-таблеток выбора модели, карточка-модалка посередине пустого экрана. Продукт — когда с первой
секунды видно дело: вердикт, блокеры, цитаты, числа.
- **Фон без пятен** (№39): спокойный `--b-canvas`; глубина — тени и бумага, а не градиенты. Шапка — тонкая
  тёмно-синяя `#0F2841` полоса со знаком-дроном 32 px слева (вместо зелёной галочки) и названием; стекло — только
  у всплывающего.
- **Главная = рабочий стол, не лендинг** (№39 + №43): сверху одна строка «Проверить документ» (поле файла и кнопка в
  одну линию), ниже сразу **последний или готовый отчёт**: вердикт, 5 блокеров с цитатой и номером строки, полоса
  чисел — как «Сегодня» в «Зерде». Лозунги и пояснения убрать. Выбор модели — одна тихая строка «Модель: Claude
  Code · sonnet — изменить» (список по нажатию), а не семь таблеток.
- **Знакомство в вебе** (№40) — только если ключа нет и терминала не было (двойной щелчок); не модалка посреди
  пустоты, а тот же рабочий стол с готовым отчётом, BCC AI в углу с репликой и полем ключа.
- **Отчёт** (№41): плотнее и по делу — строка блокера: `D-01` · суть · «строки 37–39» · критичность цветом; без
  иконок ради иконок, без эмодзи, без градиентов на кнопках, без свечений.
- Проверка: снимок рядом со снимком «Зерде» (`docs/design/bcc-ui.md`): если экран можно принять за шаблон лендинга —
  не готово. В статусе — снимки «до/после» этого дополнения.
