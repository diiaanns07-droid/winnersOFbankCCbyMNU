## Перерисовать готовые отчёты без модели (для №36)

После вливания `reports/*.html` перерисовываются из своих `.json` (документ берётся из `document.file`; модель не
вызывается, Markdown и JSON не меняются). Проверено на копии: тело HTML без `<style>`/`<script>` совпадает с прежним.

```bash
for j in reports/*.json reports/demo_answers/qr/qr.r*.json; do [ -f "$j" ] && PYTHONPATH=src python -m bcc_review.v2.render.html "$j" -o "${j%.json}.html"; done
```

`qr.json` и `qr.before.json` проверяли `source.md`, которого рядом нет, — для них документ указать явно (иначе лист
выйдет без текста: «Документ не найден»):

```bash
for j in reports/demo_answers/qr/qr.json reports/demo_answers/qr/qr.before.json; do PYTHONPATH=src python -m bcc_review.v2.render.html "$j" --doc tests/v2/fixtures/09_open/qr/source.md -o "${j%.json}.html"; done
```

Проверка после перерисовки: `grep -c 'class="ln' ФАЙЛ.html` — строк листа столько же, сколько было (у `qr*` 203–213).
