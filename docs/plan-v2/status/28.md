### Аналитик: critical с цитатой из раздела описания API → major (`905b719`, тесты `tests/v2/test_28_lens_analyst.py`)

Все разобранные ложные critical аналитика на чистых ТЗ №18 — расхождение бизнес-правила с шагом логики метода или
примером ответа API: grace_clean «шаг метода берёт платежи после даты выписки ↔ платёж уменьшает сумму» (у №05 на
v23 и у меня на v28a), qr_clean «повтор `requestId` ↔ шаг „оплачен — 410“», insurance_clean «пример ответа API ↔
критерий приёмки». Это зона архитектора и проверки набора; аналитику critical — только правило ↔ правило, критерий
приёмки, пример или цель в бизнес-части. Код: если у critical есть цитата из раздела, заголовок которого (docview)
называет API или REST, — `major` + `severity_hint = critical` (судья видит подсказку; в вердикт не идёт). Строка
цитаты — по сверке с документом, не по номеру модели. К1 официального (Ф-2 ↔ критерий приёмки, строки 38 ↔ 64) —
