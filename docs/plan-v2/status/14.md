# Статус №14 — HTML-отчёт, веб-демо, слайды

Ветка: `v2/14-html-web`. Обновлено: 27.11, 01:50 (Астана).

## Сделано

* **HTML-отчёт одним файлом** — `src/bcc_review/v2/render/html.py` + `render/html_assets/report.css`, `report.js`.
  Без внешних зависимостей и сети: стили, скрипт и `report.json` встроены, открывается двойным щелчком.
  * шапка: вердикт «Разработка / Тестирование», плитки critical/major/minor (клик — фильтр), требования,
    доля цитат, сверенных кодом; текст вердикта; «Исправить первым» (`verdict.fix_first`);
  * «Замечания»: слева документ с номерами строк, строки с цитатами подсвечены по серьёзности, сами цитаты
    размечены `<mark>`, справа от строки — метки D-xx; справа карточки с фильтрами (серьёзность, вид, линза),
    поиском, сортировкой; клик по карточке → документ прокручивается к строке, цитаты выделяются; клик по
    подсвеченной строке → к карточке; ↑/↓ по карточкам; «только строки с замечаниями», «нарезка» (R-xx и
    исключённые фрагменты);
  * вкладки: Вопросы (варианты ответа, «Скачать ответы» JSON+MD), Тест-кейсы, Чек-лист банка, Проверки
    (исполнение приёмки, попарная сверка, трассировка, глоссарий), Нарезка, Отклонённые, Паспорт;
  * печать в PDF: все вкладки подряд, без панели документа, подробности раскрыты; светлая и тёмная тема.
* Фикстура вёрстки `tests/v2/fixtures/14_report_official.json` (генератор `14_make_sample.py`): 20 замечаний
  по эталону К1–К5/С*, цитаты найдены кодом. **Это не отчёт агента**, только образец для вёрстки до живых прогонов.
* Тесты `tests/v2/test_14_html.py` — 13 зелёных (один файл без сети, подсветка каждой цитаты, вкладки,
  экранирование, отчёт без view, partial, пустой отчёт, CLI, синтаксис JS).

## Интерфейс для №01 (подключение `--export html`)

```python
from bcc_review.v2.render import html
html.write(report: dict, view: dict | None, path) -> Path    # тот же объект: html.export
html.render_html(report, view=None) -> str
html.load_view(path) -> dict          # docview.load №03, иначе запасной разбор MD/TXT
```

`view` — DocView из CONTRACT 2.1 (`ctx.view`). Без view отчёт строится, но без панели документа.
Если в `bcc_review.v2.quotes` есть `verify_quote`, он используется; иначе — упрощённый поиск.

## Решения
