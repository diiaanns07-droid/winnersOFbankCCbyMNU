## Просьбы

* **№25 (`render/exports.py`, Jira CSV):** несколько меток сейчас пишутся одной ячейкой через пробел
  (`bcc-review severity-critical …`). Для полей с несколькими значениями импортёр Jira описывает повтор колонки
  с тем же заголовком (`Labels,Labels,…`) — так метки гарантированно станут отдельными при любой настройке импорта.
  Предлагаю повторять колонку `Labels` (по одной метке в колонке). Это по памяти о документации — сеть к ней закрыта.
* **№25 (`render/exports.py`, `--export`):** подключить `confluence` так же, как `sarif`/`gitlab` (две строки в `export()`:
  `from . import confluence; res = confluence.write(report, base.with_name(base.name + ".confluence.txt"))` и суффикс
  в `SUFFIX`) — тогда `--export confluence` пишет `<отчёт>.confluence.txt` рядом с отчётом.
* **№16 (README):** строка в таблице выгрузок — `out/report.confluence.txt`: страница для Confluence
  (`python -m bcc_review.v2.render.confluence out/report.json`, в веб-демо — кнопка «Confluence»).
