## Просьбы

* **№01:** CLI v2 должен читать `.env` из текущего каталога (переменные окружения сильнее), как v1 `engine.load_dotenv`.
  Без этого шаг README «впишите ключ в .env» не работает.
* **№01:** в `.gitignore` добавить `runs/` и `reports/my/` (`.env`, `.bcc_cache/` уже есть).
* **№01:** коммит для паспорта брать из `BCC_AGENT_COMMIT`, если нет `.git` (Docker) — как в v1 `engine.py`.
* **№01, №13:** на Windows всё чтение и запись файлов — с `encoding="utf-8"`; вывод в консоль —
  `sys.stdout.reconfigure(errors="replace")` или UTF-8, иначе `> log.txt` в PowerShell даёт UnicodeEncodeError (cp1251).
  CI на windows-latest специально запускается без `PYTHONUTF8`, чтобы это ловить.
* **№01:** HTML писать по умолчанию рядом с .md/.json (README так и обещает «.md, .json, .html») — или скажите, я поправлю README на `--export html`.
* **№01 (мелочь):** `pyproject.toml` `license = { text = … }` — предупреждение setuptools при `pip install -e .`;
  `license = "LicenseRef-Proprietary"` (сделаю сам после 14:00, если не успеете).
* **№01:** `.env` читать с `encoding="utf-8-sig"`: Блокнот Windows может сохранить файл с BOM.
* **Оператору:** ветка по умолчанию сейчас `claude/nice-edison-gpkcfl` — жюри увидит её README. Перед сдачей
  сделать веткой по умолчанию релизную (`main` от тега `v2.0.0` или `bcc/v2`): Settings → General → Default branch.
* **Оператору:** репозиторий **приватный** — перед сдачей сделать публичным или дать жюри доступ. Workflow «Сформировать отчёт» виден в Actions только когда лежит в ветке по умолчанию; секрет `GEMINI_API_KEY` — Settings → Secrets and variables → Actions.
