## Решения (в рамках контракта)

* **Нумерация PDF/DOCX** — строка на строку текста блока читателя v1 (как `try_prompt.load_lines`), поэтому фикстура
  `tests/v2/fixtures/official_pdf/segment.json` остаётся верной, перегенерировать не нужно.
* **MD/TXT**: строка = строка файла; текст из блоков v1 (снята разметка); ограждения кода, `---`, разделители и пустые
  строки таблиц — пустые строки. Нумерованные пункты сохраняют номер («5. При отклонении…»), маркеры `* `/`- ` сняты.
* `section` — путь заголовков через « › » без заголовка документа (корня): «Часть A. Новый функционал › Требования к
  изменениям › Функциональные требования». Для строки-заголовка раздел включает сам заголовок.
* `src_line` для PDF/DOCX — `None` (строки исходного файла нет); `page` для DOCX — `None`.
* Нормализация цитат дополнительно к контракту: ё → е, пробел внутри числа («4 000» = «4000»), снятие обрамляющих
  кавычек и точек, ведущих `* # | -`; вхождение по границам слов предпочтительнее куска слова («Prod: —» не находит
  «Product»); цитата с «…» внутри ищется по частям в пределах 3 строк (`normalized`).
* `verified=exact` — цитата дословно есть в строке view; `normalized`/`fuzzy` — `quote` заменяется дословным текстом
  документа (в отчёт попадает только реальный текст).
* `verify_candidates`: у оставленного кандидата доказательства `missing` убираются, на кандидате ставятся
  `line_start/line_end/page/section` первого найденного доказательства; дубли доказательств (та же строка и текст)
  схлопываются; кандидат без найденных цитат → `rejected` (весь кандидат + `reason: "цитата не найдена"`).
* `bcc_review/v2/__init__.py` не создаю (файл №01): до каркаса пакет работает как namespace-пакет.

## Просьбы

* №01: точка вызова сверки — после линз/набора/правил: `quotes.verify_candidates(ctx.view, candidates, ctx.requirements)`;
  `stats["share_verified"]` — для `summary.quotes_verified`. Для `report.document` — `docview.summary(view)`.
* №04: после нарезки можно вызвать `quotes.verify_requirements(view, requirements)` — уточнит `line_start/line_end/page`.
* №13: `docview.place(view, a, b)` даёт готовую строку места («с. 2, строка 25»).
