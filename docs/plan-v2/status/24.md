## Итог релизной дорожки (27.11, 18:10)

**Сценарий жюри с Gemini без ключа — проверен честно:** CLI `python -m bcc_review ТЗ отчёт.md --provider gemini`
отдельным процессом → настоящий SDK `google-genai` → настоящий HTTP к поддельному серверу Gemini
(`tests/v2/fixtures/24_gemini/fake_gemini.py`, адрес через `GOOGLE_GEMINI_BASE_URL`, который читает сам SDK).
Сервер отвечает записанными ответами этапов (этап — по строке промпта) и по сценарию — отказами.

| Отказ | Где | Итог прогона |
| :--- | :--- | :--- |
| нет отказов | — | complete, «нельзя», 3 блокера, 109/109 цитат |
| пустой ответ, нет кандидатов, 400 «схема слишком сложная», обрыв соединения, 429 + Retry-After, 503, обрезанный JSON — **все разом**, по одному на этап | 7 этапов | **complete, «нельзя»** |
| 503 у основной модели всё время | все | complete на `gemini-3.7-flash` |
| дневная квота основной модели | все | complete, основная вызвана 1 раз |
| блок безопасности (promptFeedback) | судья | partial, «нельзя» (реестр кодом) |
| finishReason SAFETY | линза рисков | partial с причиной «фильтр» |
| неверный ключ / квота на всей цепочке / нет сети | все | отчёт правилами, «не вынесен», русская причина первой строкой, код 3 |

Ни одного падения и ни одного ложного «можно». Провайдер отдельно (настоящий HTTP): 429 ждёт ровно Retry-After
из заголовка; 429 дольше 65 с → запасная модель; 503/500/504/обрыв/обрезанный JSON/пусто — повтор на той же модели;
стойкий отказ → следующая модель (503 — 4 попытки, пусто/обрезка — 2, 404/квота — 1); тайм-аут клиента — повтор;
блок, MAX_TOKENS, неверный ключ — сразу наверх одним запросом (не тратим 20 суточных); нет сети — 3 запроса и стоп.
**`--rpm`:** 5 параллельных этапов при окне 2 запроса — на сервер не больше 2 за окно (фактический темп по журналу
сервера). На прогоне по умолчанию окно Flash 5/мин: 9 запросов, шестой ждёт окно (~60 с), 429 нет.

Тесты: `test_24_jury_gemini.py` (9 прогонов CLI), `test_24_gemini_faults.py` (24), `test_24_doctor_live.py` (17),
`test_24_claude_cli_windows.py` (7) — **57 зелёных, 35 с**. Весь набор `pytest tests/v2 -n 8`: **1814 passed**,
1 skipped, 2 xfailed, 7 xpassed, красных 0. `evaluation.v2.antifit` — чисто.
