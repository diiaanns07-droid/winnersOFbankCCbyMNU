## Решения
* Противоречия правил по сути (К2) — зона №09; аналитик ловит их как «неоднозначность взаимодействия», это нормально
  для судьи (дедупликация). Расхождение единиц/границ одной величины — в зоне аналитика (дало 4/4 на мутантах).
* critical у аналитика — только с типом расхождения (`event_conflict`, `boundary_conflict`, `unit_mismatch`,
  `contradiction`, `status_conflict`) и цитатой второго места; правило продублировано кодом в `postprocess`.
* Неединичность — одно замечание `minor` на документ.
* Названное событие («выполнен», «проведена») = определённое; дефект — только разные события в связанных правилах.

## Ответ №01 (объявление 03:08: «ответ линзы на haiku > 16 000 токенов»)
Ограничения в промпте уже есть: ≤ 12 кандидатов, каждое поле — 1–3 предложения, `title` ≤ 100 символов; итоговый
JSON аналитика на haiku — 10–14 тыс. символов (≈ 4–6 тыс. токенов). Остальное — **скрытое рассуждение модели**,
промптом оно почти не управляется. Замер (`claude -p --output-format stream-json`, haiku, промпт v11): один успешный
вызов `StructuredOutput`, повторов по схеме нет; токенов вывода 51–55 тыс., 230–250 с. Поэтому в `lens_analyst.run`
лимит 32 000 (этап проходит одним вызовом, без деления).

**Предложение №02 (провайдеры), проверено:** ограничить рассуждение снаружи. `MAX_THINKING_TOKENS=8000` для `claude -p`:
haiku — 125 с вместо 230–250 с, вывод 29 тыс. вместо 55 тыс., качество то же (счётчик №15: К1, К2, К4; С 6/20, нестрого
7/20; в эталоне 10 из 12, ложных 0). `MAX_THINKING_TOKENS=0` CLI игнорирует. Для Gemini Flash — аналогично
`thinkingConfig.thinkingBudget` ≈ 8 192 (рассуждение входит в лимит вывода).

## Просьбы

  например, читать `MAX_OUTPUT_TOKENS` из модуля `lens_<имя>.py`, как `SCHEMA`, или поднять общий до 32 000.
* **№01:** после `lens.run(ctx, "analyst")` вызывать `stages.lens_analyst.postprocess(candidates)` или звать
  `lens_analyst.run(ctx)` вместо общего запуска — страховка калибровки для слабых моделей.

  К4, а не к С14 — при общей строке-опоре решать по ключевым словам; (2) коды валют (USD, EUR, RUB) — в
  `LATIN_ALLOW`, это не английский текст.
