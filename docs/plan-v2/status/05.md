## Решения
* Мутантов типа ambiguity в корпусе нет; для проверки взяты unit_change ×2 и range_boundary ×2.
* Противоречия правил по сути (К2) — зона №09; аналитик берёт только неоднозначную формулировку и расхождение
  единиц/границ одной величины (это дало 4/4 на мутантах без шума на чистых).
* critical у аналитика — только если другое место документа прямо поддерживает иное толкование (убрало ложные
  critical на чистых базах).
