| `revise_stats.warnings` | `--revise` (с `a5bb9d6d`) | что код не внёс в редакцию и почему | под «Исправленная редакция»: «Не внесено кодом: …» |

**Формат файла ответов для «Скачать ответы» (№34)** — то, что разбирает `recheck.parse_answers_text`:

```
# Ответы владельца
> Документ: requirements.md, SHA-256 <64 знака или первые 12>
Q-01 [тема вопроса]: B — текст варианта B
Q-02 [тема (со скобками можно)]: свой текст ответа
Q-03 [тема]: ?

## Решения
- общее решение без вопроса
```

Строки `>` и `#` — пояснения (их ответами не считают); тема в квадратных скобках — по ней ответ найдёт вопрос, если
номера сменятся; после буквы — текст варианта (если варианты переставятся, ответ сверят по тексту). Готовая функция —
`recheck.answers_file_text(questions, {"Q-01": "B", …}, document=, sha256=, decisions=[…])`.
