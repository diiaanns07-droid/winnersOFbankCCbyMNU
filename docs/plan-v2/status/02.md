### 1. Симулятор бесплатного тарифа (`tests/v2/test_02_free_tier.py`, 7 сценариев, без сети)

Полный прогон официального документа как у жюри: `python -m bcc_review ВХОД ОТЧЁТ.md --provider gemini` → pipeline →
LLMClient → GeminiProvider → **настоящий** адаптер v1 и типы google-genai. Подменён только сетевой клиент: «сервер»
ведёт окно запросов в минуту (429 с RetryInfo), дневную квоту (429 PerDay), волны 503, снятую модель (404); ответ
этапа — записанный ответ из mock-фикстур. Время модельное (паузы считаются, но не ждутся).

| Сценарий | Статус | Запросов к API | Исходы | Пауз провайдера | Фактические модели |
| :--- | :--- | :---: | :--- | :---: | :--- |
| 10 запросов/мин, ответ 20 с | complete (код 0) | 9 | 200 ×9 | 0 с | gemini-3.8-flash |
| 3 запроса/мин, залп без задержки | complete (код 0) | 11 | 200 ×9, 429 ×2 | 123 с | gemini-3.8-flash |
| волна 503 ×12 у основной | complete (код 0) | 21 | 503 ×12, 200 ×9 | 51 с | gemini-3.6-flash, gemini-3.8-flash |
| основная модель снята (404) | complete (код 0) | 10 | 404 ×1, 200 ×9 | 0 с | gemini-3.6-flash |
| дневная квота: основная 0, вторая 2 | complete (код 0) | 11 | 429-день ×2, 200 ×9 | 0 с | gemini-3.6-flash, gemini-3.5-flash-lite |
| дневные квоты всех трёх моделей 0 | failed (код 3) | 3 | 429-день ×3 | 0 с | — |
| неверный ключ | failed (код 3) | **1** | 400 API_KEY_INVALID | 0 с | — |

В двух последних случаях отчёт всё равно строится правилами. Первая строка предупреждений:
«Дневная квота бесплатного ключа Gemini исчерпана на всех моделях цепочки. Квота восстановится около 13:00 завтра по
местному времени…» / «Google не принял ключ Gemini (GEMINI_API_KEY): проверьте, что он скопирован целиком…».

Настройки под бесплатный тариф (по умолчанию, менять не нужно): параллельность `GEMINI_CONCURRENCY=4` (5 линз+набор
идут в 4 потока — укладывается в 10 запросов/мин); 429 — ждём Retry-After из ответа (≤ 65 с, до 2 раз), потом
следующая модель; 503 — 2/5/10 с, потом следующая модель; `thinking_level=medium`; `max_output_tokens` не ниже
32 000. Квоты бесплатного ключа считаются **по каждой модели отдельно**, поэтому цепочка из трёх моделей примерно
утраивает число прогонов в день. Один прогон — 9 запросов.

### 3. Ошибки для жюри — первой строкой и по-русски

`doctor.headline(exc, provider)` — одна строка «что случилось и что сделать», `doctor.explain` — та же строка +
«Подробности: <ответ сервера>». Понимает и `ProviderError`, и обёртку `LLMError` из `llm.py` (раньше получалось
«Ошибка: segment: auth: …» без совета). Сценарии (тест `test_headline_for_jury_scenarios`):

| Ситуация | Первая строка |
| :--- | :--- |
| нет ключа | Не задан ключ Gemini. Получите бесплатный ключ на https://aistudio.google.com/apikey и добавьте в файл .env строку GEMINI_API_KEY=<ключ>. |
| неверный ключ | Google не принял ключ Gemini (GEMINI_API_KEY): проверьте, что он скопирован целиком, без кавычек и пробелов, или создайте новый на https://aistudio.google.com/apikey. |
| дневная квота | Дневная квота бесплатного ключа Gemini исчерпана на всех моделях цепочки. Квота восстановится около ЧЧ:ММ сегодня/завтра по местному времени (полночь по тихоокеанскому времени США); сейчас можно взять другой ключ. |
| лимит в минуту | Превышен лимит запросов в минуту бесплатного ключа Gemini (агент уже ждал и повторял). Повторите через N с; можно уменьшить параллельность: GEMINI_CONCURRENCY=2 в .env. |
| модель недоступна | Модели Gemini из цепочки недоступны этому ключу. Список доступных моделей: python -m bcc_review doctor; затем GEMINI_MODEL=<модель> в .env. |
| нет сети | Нет соединения с Google Gemini (generativelanguage.googleapis.com): проверьте интернет, прокси (HTTPS_PROXY) и брандмауэр. |
| нет пакета | Не установлен нужный пакет google-genai: выполните «pip install -r requirements.txt» и повторите. |

Время сброса дневной квоты считается без `zoneinfo` (на Windows без `tzdata` его нет): полночь по тихоокеанскому
времени США (PST/PDT по правилу переходов) → местное время машины.

## Лимит ответа (важно)

Этапы передают `max_output_tokens` 8 000–16 000 (линзы — 16 000). Рассуждения модели входят в тот же лимит: haiku
на линзе выдал 31 тыс. токенов. Поэтому лимит этапа у провайдера **не опускает** лимит ниже своего:
`claude_cli` — не ниже 64 000 (`CLAUDE_CODE_MAX_OUTPUT_TOKENS`, если не задан пользователем), gemini и anthropic —
не ниже 32 000, openai — не ниже 16 000 (если `OPENAI_MAX_TOKENS` задан явно — он главный: контекст локальной модели).
До этой правки haiku через CLI обрезался бы на каждой линзе.
