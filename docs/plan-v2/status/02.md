| Провайдер | Класс | Что внутри |
| :--- | :--- | :--- |
| `claude_cli` | `ClaudeCLIProvider` | `claude -p --output-format json --tools "" --model M --json-schema S --system-prompt-file F --no-session-persistence --strict-mcp-config [--effort E] [--fallback-model …]`; текст — через stdin, системный промпт — во временном файле (нет лимита 32 КБ командной строки Windows). Разбор `structured_output` (или JSON из `result`), `usage` (вход = свежие + запись в кэш + чтение кэша), `total_cost_usd`, фактическая модель из `modelUsage`. Ошибки по `api_error_status`/`api_error_type`/тексту → `ProviderError` (404 not_found, 429 rate_limit, 529 overloaded, 5xx server, 401 auth, «usage limit» quota с `retry_after_s` по времени сброса, 400 bad_request, тайм-аут, нет программы → not_configured с командой установки). Windows: `claude.exe`, иначе `node …/cli.js` рядом с `claude.cmd` (через cmd.exe пустой `--tools ""` и кавычки JSON ломаются). Env: `CLAUDE_CLI_MODEL` (opus), `CLAUDE_CLI_EFFORT`, `CLAUDE_CLI_FALLBACK_MODEL` (по умолчанию sonnet, для sonnet — opus; `off`), `CLAUDE_CLI_BIN`, `CLAUDE_CLI_TIMEOUT_S` (нижняя граница, 600 с), `CLAUDE_CLI_LOG`. |
| `gemini` | `GeminiProvider` | Обёртка над v1 `bcc_review.providers.gemini.GeminiAdapter` (санитайзер схемы, классификация ошибок, строгая проверка ответа) — решение после чтения кода: v1 крепкий, не хватало политики надёжности. Модель `gemini-3.8-flash`, цепочка `GEMINI_FALLBACK_MODELS` (по умолчанию `gemini-3.6-flash,gemini-3.5-flash-lite`, `off` — без неё). 503/500/504/тайм-аут — 3 повтора с паузой 2/5/10 с, затем следующая модель; 404 и квота — сразу следующая, модель отключается до конца прогона; 429 — ждём Retry-After (≤ 65 с, до 2 раз), иначе следующая модель; нет сети — 2 повтора и ошибка; auth/bad_request/refusal/truncated/invalid_output — сразу наверх. `max_output_tokens` 32 000; thinking: Gemini 3 — `thinking_level=medium`, 2.5 — `thinking_budget=4096`; если модель отвергла thinking (400) — повтор без него. Ответ: `model` = фактическая `model_version`, `meta.attempts`, `meta.fallback_used`, `meta.called_model`. Общий бюджет времени вызова `3×timeout_s+60` (`GEMINI_TOTAL_TIMEOUT_S`), параллельность `GEMINI_CONCURRENCY` (4). Ключ: `GEMINI_API_KEY` или `GOOGLE_API_KEY`. |
| `anthropic` | `AnthropicProvider` | Обёртка над v1 `AnthropicAdapter` (SDK `anthropic==2.14.0`, structured outputs, проверка схемы). В `messages` только `role`/`content`; `cache_control` на system и на префиксе документа (всё до последнего закрывающего тега `</…>` на отдельной строке, если ≥ 2000 символов); задание этапа — отдельным блоком. `max_tokens` 32 000, без лишнего `GET /v1/models`. 400 про beta/fallback или effort → тот же запрос без них, режим запоминается. Сквозной тест через настоящий SDK: в теле запроса нет поля `cache`. |
| `openai` | `OpenAICompatProvider` | `OPENAI_BASE_URL` (+`/v1`, если нет) + `OPENAI_MODEL` (+`OPENAI_API_KEY`); только `urllib` (нет зависимостей — подходит для закрытого контура: Ollama, vLLM, LM Studio, OpenRouter). `response_format` json_schema → при 400 о формате json_object → без формата (схема текстом в system); режим запоминается; ответ разбирается (```json```, `<think>…</think>`, первый `{…}`) и проверяется `jsonschema`. Ошибки: 401/403 auth, 404 not_found (совет `ollama pull`), 429 rate_limit/quota с Retry-After, 502/503 overloaded, 504 timeout, отказ соединения → network («ollama serve»), `finish_reason=length` → truncated, переполнение контекста → bad_request с советом про `num_ctx`. |
| выбор и ошибки | `doctor.make_provider`, `resolve_auto`, `explain` | `auto`: GEMINI_API_KEY/GOOGLE_API_KEY → gemini; ANTHROPIC_API_KEY → anthropic; OPENAI_BASE_URL → openai; есть `claude` → claude_cli; иначе offline (`make_provider` вернёт `None`). Алиасы: `claude`, `ollama`, `vllm`, `none`… `explain(exc, provider)` — 1–2 строки по-русски «что случилось / что сделать» на каждый `kind` × провайдер, без трейсбэка. |
| `doctor` | `doctor.main(argv)` | Python, пакеты (jsonschema обязателен; google-genai, anthropic, pymupdf, python-docx — для чего нужны и как поставить), ключи («задан/не задан», значения не печатаются), настройки моделей, `claude --version`, выбранный провайдер и почему, для Gemini — цепочка моделей и `models.list` (какие модели есть у ключа, какие Flash доступны); `--live` — пробный вызов с коротким JSON (модель, время, токены, ответ). Маркеры ASCII `[ок]`/`[нет]`/`[!]` (кодировка консоли Windows). Коды: 0 готово, 1 нет рабочего провайдера, 2 пробный вызов не прошёл. Читает `.env`. |

Все провайдеры: `invoke(*, model, messages, schema, timeout_s, max_output_tokens=None, **_)` →
`{"data", "usage": {"input_tokens", "output_tokens", …}, "model", "request_id", "stop_reason": "end_turn"|"max_tokens", "cost_usd"?, "meta"}`;
ошибки — `bcc_review.contracts.ProviderError(kind, message, retry_after_s=…)`. Атрибут `handles_retries`:
`True` у gemini (повторы и цепочка внутри), `False` у остальных.

## Gemini: команда проверки на Windows (для №17 и оператора)

Ключа Gemini в облачном окружении нет. Проверка на Windows (PowerShell, из корня репозитория):

```powershell
git fetch origin; git switch v2/02-providers
py -3.12 -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -e ".[gemini]"
Set-Content -Encoding utf8 .env "GEMINI_API_KEY=<ваш ключ из https://aistudio.google.com/apikey>"

python -m bcc_review.v2.providers.doctor --live --provider gemini
```

Ожидаемо: «[ок] gemini-3.8-flash» в списке моделей ключа и «Модель ответила за N с: gemini-3.8-flash…». Если
основной модели у ключа нет — doctor покажет, какие Flash доступны; задать `GEMINI_MODEL=<модель>` в `.env`.

## Просьбы

* **№01 (llm.py):** (1) создавать провайдер через `bcc_review.v2.providers.doctor.make_provider(name, model=…)`
  (`None` для offline); (2) если у провайдера `handles_retries = True` (gemini) — не повторять временные ошибки
  поверх: провайдер уже сделал 3 повтора и прошёл цепочку моделей; для остальных — повторы `LLMClient`;
  (3) обрезанный ответ приходит как `ProviderError(kind="truncated")` (gemini, anthropic, openai, claude_cli) —
  это сигнал для `ask_split`; (4) `max_output_tokens` можно передать в `invoke` именованно; (5) фактическая модель —
  `result["model"]`, стоимость — `result.get("cost_usd")` (claude_cli), попытки — `result["meta"]`;
  (6) для вывода пользователю — `doctor.explain(exc, provider_name)` (русский текст без трейсбэка);
  (7) маршрут `python -m bcc_review doctor [--live] [--provider P] [--model M]` → `bcc_review.v2.providers.doctor.main(argv)`.
* **№16:** в `requirements.txt` — `jsonschema`, `google-genai>=3.6,<4`; `anthropic==2.14.0` — по желанию; в `.env.example` —
  `GEMINI_API_KEY=`, `GEMINI_MODEL=gemini-3.8-flash`, `GEMINI_FALLBACK_MODELS=gemini-3.6-flash,gemini-3.5-flash-lite`,
  `OPENAI_BASE_URL=`, `OPENAI_MODEL=`; в README — `python -m bcc_review doctor --live` как первый шаг.
* `src/bcc_review/v2/__init__.py` и `providers/__init__.py` — пустые, созданы для тестов; при слиянии с каркасом
  берётся версия каркаса (№01).
