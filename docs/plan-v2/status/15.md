## Сделано

* `evaluation/v2/official/gold.yaml` — эталон: К1–К5, С1–С20, М1–М8 (М2, М4 по частям); строки-опоры с цитатами
  (у конфликтов — обе стороны), ключевые слова, допустимые `kind`, владельцы-линзы.
* `python -m evaluation.v2.score report.json [--run-dir runs/<id>] [--arbiter sonnet]` — recall К/С/М (строгий и
  нестрогий), серьёзность, дубли, вне эталона (арбитр), критичные ложные, цитаты, общие фразы, английский,
  разделы п. 6 ТЗ, длина, время, вызовы, ворота; разбор промахов: «никто не нашёл» / «линза нашла, судья не взял» /
  «отсеяно сверкой цитат». Читает отчёты v1 (план Б) и выход отдельной линзы (`--lens`).
* `python -m evaluation.v2.measure --label … --provider claude_cli --model sonnet` — замер одной командой: прогон,
  оценка с арбитром, `history.jsonl`, таблица в `RESULTS.md`.
* `python -m evaluation.v2.corpus run --out DIR --provider claude_cli --model haiku --label … --save` — корпус через
  строгий счётчик `evaluation/harness` + вердикты и серьёзность на чистых.
* `python -m evaluation.v2.aggregate stability|models …` — стабильность (3/3, 2/3, 1/3) и сравнение моделей.
* `python -m evaluation.v2.antifit` и тест: промпты v2 чистые (проверено на `bcc/v2` 09f0dfb).
