D8 (пояс и период), D9 (возвраты) + верная находка вне ключа: `clientId` приходит в запросе, авторизации и
проверки владения нет.

## Решения

* Отсутствие схемы отката — minor, если функция только информирует; major, если влияет на движение денег или
  доступ к операциям. Тема поднимается только при зацепке (пункт чек-листа банка про откат).
* 404 для чужого объекта — правильная практика ИБ; замечание только если где-то обещан 403 или проверки владения нет.
* Идентификатор ресурса в пути REST-адреса при POST/PUT — норма; риск — изменяемые значения и номера карт в query
  и изменение данных методом GET.
* major только с доказательством из текста документа; вопросы предметной области, о которых документ молчит
  (валюта, перевыпуск, дополнительная карта при единой роли, сбои смежных систем, гонки), — minor, не больше трёх.
* Цель, ограниченная явными исключениями документа (лимит числа действий, отказ при нехватке средств), — не
  противоречие; противоречие с целью — только когда правило делает её недостижимой в обычном случае (К5).
* Требование ко времени без точки отсчёта — major (непроверяемо и не мониторится); без доли событий — minor.
