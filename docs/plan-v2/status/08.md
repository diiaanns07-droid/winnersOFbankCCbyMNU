### Просьбы второй волны

* **№10 (судья), К5:** линза подаёт К5 строго под (б) — `ambiguity/unambiguous`, «не определено, какой этап операции
  запускает основную функцию», два толкования для каждой операции, последствия для основной функции и НФТ.
  В прогоне №01 04:14 судья склеил его с кандидатом аналитика «цель несовместима» (`criterion=language`, major) и
  выдал F05 major. Просьба: при склейке кластера с `ambiguity`-кандидатом линзы о ключевом событии брать его
  основание (б) и уровень; «расхождение с целью» не считать причиной major, если в кластере есть кандидат о
  неопределённом событии. Проверка (`judge_check`) по тексту (б) уже это позволяет.
* **№10:** противоречие с критерием приёмки линза больше не выдаёт (снимается как дубль тестировщика) — К1 приходит
  только от `lens:qa`; К2 — от набора.
* **№02 (claude_cli), скорость haiku:** `claude -p --effort low` для haiku срезает рассуждения: линза — 53 с и
  11,6 тыс. токенов вместо 117–262 с и 27–60 тыс., качество то же (К5 critical, С 10/20, 0 ложных). Предлагаю
  `--effort` из переменной окружения (например `CLAUDE_CLI_EFFORT`, по умолчанию `low` для haiku) — это путь к
  цели «haiku complete ≤ 8 мин» для всех этапов. Проверка: `EFFORT=low python try_effort.py …` (обёртка над
  `try_prompt.py`, добавляет флаг к вызову).

## Решения

* Отсутствие схемы отката — minor, если функция только информирует; major, если влияет на движение денег или
  доступ к операциям. Тема поднимается только при зацепке (пункт чек-листа банка про откат).
* 404 для чужого объекта — правильная практика ИБ; замечание только если где-то обещан 403 или проверки владения нет.
* Идентификатор ресурса в пути REST-адреса при POST/PUT — норма; риск — изменяемые значения и номера карт в query
  и изменение данных методом GET.
* major только с доказательством из текста документа; вопросы предметной области, о которых документ молчит
  (валюта, перевыпуск, дополнительная карта при единой роли, сбои смежных систем, гонки), — minor, не больше трёх.
* Цель, ограниченная явными исключениями документа (лимит числа действий, отказ при нехватке средств), — не
  противоречие; противоречие с целью — только когда правило делает её недостижимой в обычном случае (К5).
* Требование ко времени без точки отсчёта — major (непроверяемо и не мониторится); без доли событий — minor.
