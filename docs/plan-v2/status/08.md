## Решения

* Отсутствие схемы отката — minor, если функция только информирует; major, если влияет на движение денег или
  доступ к операциям. Тема поднимается только при зацепке (пункт чек-листа банка про откат).
* 404 для чужого объекта — правильная практика ИБ; замечание только если где-то обещан 403 или проверки владения нет.
* Идентификатор ресурса в пути REST-адреса при POST/PUT — норма; риск — изменяемые значения и номера карт в query
  и изменение данных методом GET.
* major только с доказательством из текста документа; вопросы предметной области, о которых документ молчит
  (валюта, перевыпуск, дополнительная карта при единой роли, сбои смежных систем, гонки), — minor, не больше трёх.
* Цель, ограниченная явными исключениями документа (лимит числа действий, отказ при нехватке средств), — не
  противоречие; противоречие с целью — только когда правило делает её недостижимой в обычном случае (К5).
* Требование ко времени без точки отсчёта — major (непроверяемо и не мониторится); без доли событий — minor.

* **№02 (claude_cli), срочно, мешает слабым моделям:** `claude -p` при переполнении пишет
  «API Error: Claude's response exceeded the 16000 output token maximum…». `classify_cli_result` ищет только
  «max_tokens» / «max output tokens», поэтому ошибка уходит в `unknown`, `LLMClient` не поднимает `Truncated`,
  и `ask_split` не делит пакет — этап падает целиком (haiku на официальном документе: 3 линзы из 5 упали
  через ~300 с). Правка: добавить в проверку обрезки `"output token maximum"` (или `"exceeded the"` +
  `"output token"`). Проверено: с `CLAUDE_CODE_MAX_OUTPUT_TOKENS=32000` тот же этап проходит (157 с, 12 кандидатов).
  Причина объёма — скрытые рассуждения haiku (35 тыс. токенов вывода при JSON ≈ 9 тыс.); можно ещё
  ограничить их `MAX_THINKING_TOKENS` для `claude_cli`.
* №01: в `stages/lens.py` `MAX_OUTPUT_TOKENS = 16000` — для `claude_cli` с рассуждениями этого мало; после правки
  №02 сработает деление, но можно и поднять лимит до 32000 (Gemini и API — как есть).
* №10 (судья): у линзы «Риски» К1 и К2 иногда дублируют находки набора/тестировщика — склеивайте по цитатам.
