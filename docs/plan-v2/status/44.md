## Найдено в порядке влияния на жюри

1. **P0. Получение репозитория без доступа.** Шаг — открыть ссылку и скачать проект. README предлагает обычный HTTPS-клон. GitHub под аккаунтом владельца сообщает `visibility=PRIVATE`. Без входа страница и API репозитория возвращают HTTP 404, протокол Git — HTTP 401. Контрольный запрос к открытому ТЗ организаторов — HTTP 200. Жюри без выданного доступа останавливается до установки. **Исправление** — предоставить жюри согласованный доступ к релизу и проверить ссылку из отдельного аккаунта судьи. Альтернатива — отдельный разрешённый к публикации комплект сдачи.
2. **P0. Команда клонирования из README ведёт к ветке с документацией.** Шаг — скопировать первую команду быстрого старта. Она не указывает ветку. GitHub отдаёт по умолчанию `claude/nice-edison-gpkcfl`; на момент проверки в её корне только `docs/`. Ветки `release` и `bcc/v2` показывают `1933b20c`. **Исправление** — писать `git clone --branch release --single-branch https://github.com/diiaanns07-droid/winnersOFbankCCbyMNU.git bcc-review`, затем `cd bcc-review`; ссылку для просмотра вести на `/tree/release`.

3. **P0 на этой сети. Полный клон оборвался через 560,20 с (9 мин 20 с).** Шаг — `git clone -b release … bcc-review` с доступом владельца. Git завершился с кодом 128, `curl 18`, `early EOF`, `invalid index-pack output`. Рабочая директория после ошибки отсутствовала. Это отдельный сетевой сбой, воспроизведённый после успешной авторизации. **Исправление** — короткий клон одной ветки в быстрый старт; для слабой сети дать версионный архив или короткий маршрут без истории и тяжёлых материалов. Эксперимент с частичным клоном вернул корневые файлы за 8,61 с; время получения рабочих подкаталогов измеряется отдельно.
4. **P0 для просмотра результата без установки.** На `1933b20c` в README проверены 11 ссылок на файлы и 2 ссылки на каталоги, отсутствуют 3 цели. В SUBMISSION из 21 файловой ссылки девять ведут на отсутствующие файлы. Всего семь уникальных путей: `reports/requirements.md`, `reports/requirements.html`, `reports/requirements.json`, `reports/requirements_pdf.md`, `reports/requirements.gemini.md`, `reports/other_topic_cashback.md`, `presentation/deck.pdf`. Видео и файл субтитров присутствуют. **Исправление** — включить финальные артефакты в сдаваемый коммит, перепроверить все ссылки в обеих инструкциях и повторить загрузку от имени судьи.
5. **P1. Буквальная команда выбора Python.** README объявляет поддержку 3.11–3.14, но первой командой требует `py -3.12`. На ноутбуке `py -3.12 --version` возвращает 103 и сообщение `No suitable Python runtime found`. Объяснение замены расположено после обоих блоков установки. **Исправление** — до блока сообщить о выборе уже установленной версии; `py -3.14` на этом компьютере успешно создал изолированное окружение за 8,67 с. Проверен Windows PowerShell 5.1.26100.9818, политика текущего пользователя RemoteSigned.
