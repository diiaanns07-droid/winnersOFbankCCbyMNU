## Найдено в порядке влияния на жюри

1. **P0. Получение репозитория без доступа.** Шаг — открыть ссылку и скачать проект. README предлагает обычный HTTPS-клон. GitHub под аккаунтом владельца сообщает `visibility=PRIVATE`. Жюри без выданного доступа останавливается до установки. **Исправление** — предоставить жюри согласованный доступ к релизу и проверить ссылку из отдельного аккаунта судьи. Альтернатива — отдельный разрешённый к публикации комплект сдачи.
2. **P0. Команда клонирования из README ведёт к ветке с документацией.** Шаг — скопировать первую команду быстрого старта. Она не указывает ветку.
