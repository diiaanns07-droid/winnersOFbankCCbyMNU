## Прошу №44 проверить на Windows (свежий клон `release`)

1. `git clone -b release https://github.com/diiaanns07-droid/winnersOFbankCCbyMNU bcc-review; cd bcc-review; .\START.cmd`
   в **Windows PowerShell 5.1** — без вопросов, одна строка прогресса, затем рамка «BCC Review работает: …» и браузер.
2. То же двойным щелчком по `START.cmd` в Проводнике; русский текст в окне не «кракозябры».
3. Папка с пробелом и кириллицей, например `C:\Users\<имя>\Рабочий стол\BCC Review` (или «Code → Download ZIP» →
   распаковать туда → двойной щелчок `START.cmd`).
4. Повторный `.\START.cmd` — без «Устанавливаю зависимости», сервер за секунды.
5. Занять порт: во втором окне ещё раз `.\START.cmd` → «Веб-демо уже запущено: http://127.0.0.1:8014/» и браузер;
   если 8014 занят чужой программой — «Порт 8014 занят … запущено на порту 8015».
6. `.\START.cmd --check` — «Проверка: …/healthz — ok», «Установка в порядке», код выхода 0 (`echo $LASTEXITCODE`).
7. Ctrl+C останавливает сервер; окно cmd спрашивает «Завершить выполнение пакетного файла [Y(да)/N(нет)]?» — это норма.
8. Если на ноутбуке нет Python: `START.cmd` спрашивает Y/N про winget; на «Y» ставит 3.12 и продолжает в том же окне.
9. `git ls-files --eol START.cmd start.ps1` → `w/crlf`; `start.ps1` в Блокноте — кириллица читается.
10. Docker Desktop (если есть): `docker compose up` → http://localhost:8014 открывается, без `.env` не падает.

Если что-то не так — пришлите строку ошибки целиком в `status/44.md`, я поправлю.
