## Что сделано

- **`agent.js`** (≈22 КБ, без зависимостей): дрон «Review Agent» перенесён с титульного слайда без изменений рисунка
  (`makeDrone`, `DSK`, режимы `idle`, `scanning`, `analyzing`, `verified`, `alert`, моргание, взгляд за курсором,
  луч сканера, искры один раз при `verified`). API: `BCCAgent.mount(el, {size, mood, say}) → agent`,
  `agent.mood(имя[, мс_до_idle])`, `agent.say(текст) → Promise` (≈10 мс на символ, щелчок — сразу), `agent.destroy()`.
  Автоподключение `[data-bcc-agent]` (`data-size`, `data-mood`, `data-say`), в том числе для узлов, добавленных позже.
  Один `requestAnimationFrame` на всех; рисует только видимые (IntersectionObserver) и только при открытой вкладке;
  `prefers-reduced-motion` — статичный кадр. Холст по `devicePixelRatio`, `image-rendering: pixelated` — чётко на 2×.
- **`agent.css`**: тёмно-синяя плитка (радиус 28 %, градиент `#20395A → #070B16`, кромка), стеклянное облачко,
  на ширине ≤ 560 px облачко под плиткой; `prefers-reduced-motion`. Работает и без `tokens.css` (запасные значения).
- **`/welcome`** (`onboarding.py`): `GET /` → 303 `/welcome`, если провайдер «auto», это не показ по `--fixture`,
  нет ни одного готового `claude_cli`/`gemini`/`anthropic`/`openai` и нет cookie `bcc_nokey=1`. Три капсулы,
  поле с точками и «показать», «Проверить ключ» → `analyzing` → `verified` + «Ключ работает · AIza…3f9Q» + флажок
  «Запомнить… (.env)» → «Открыть систему»; ошибка → `alert` и одна красная строка. «Без ключа» → `/welcome/skip`
  (cookie на год) → система, провайдер `auto` даёт `offline`.
- **`POST /api/key`**: проверка — `doctor.run_doctor(live=True, provider=…, timeout_s=9)`, т. е. ровно
  `doctor --live`; ключ кладётся в `os.environ` сразу, в `.env` (текущий каталог) — только при `remember`, прочие
  строки не трогаются, прежнее значение заменяется, права 600. 403 при чужом `Origin` (пустой, `127.0.0.1:порт`,
  `localhost:порт` — можно; для Docker с другим внешним портом — если `Origin` совпадает с `Host` на localhost).
  Ключа нет в ответе, журнале и HTML — только маска. Повторная отправка уже проверенного ключа модель не вызывает.
- Хелпер для главной: `onboarding.status_line(cookie)` → «Gemini · ключ проверен» / «Без ключа: только правила и
  готовые отчёты» (№39 уже показывает свою строку — можно не использовать).
- Живая проверка на поддельном ключе (без модели, Google отвечает за ~1 с): «Ключ не подошёл: Google ответил 400.
  Скопируйте ключ целиком.»
