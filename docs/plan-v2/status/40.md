## Что сделано

- **Терминал — первое знакомство** (`tty_agent.greet(port, env_path) -> str`, только стандартная библиотека).
  Тот же пиксельный дрон полублоками `▀`: 24-битный цвет, иначе 256 цветов, иначе маленький ASCII; на Windows
  включается VT-режим. Дрон моргает и печатает «Здравствуйте! Я BCC AI — проверяю ТЗ до начала разработки.»,
  спрашивает ключ Gemini или Claude (ввод скрыт, «Enter — без ключа»). Проверка — тот же код, что `doctor --live`,
  пока она идёт, дрон анализирует. «Ключ работает. Запомнить на этом компьютере? [Д/н]» → `.env` (права 600).
  Если ключ уже есть — «С возвращением!» и сразу браузер. Ошибка — одна строка «что сделать», три попытки.
  Возвращает `gemini` / `anthropic` / `claude_cli` / `openai`, `offline` (Enter или попытки кончились) или `''`
  (нет терминала и нет ключа — одна строка со ссылкой на `/welcome`). Окно меньше 72×30 — дрон вдвое меньше.
- **Дрон над листом** (`agent.js`): `BCCAgent.fly(sheet, {size: 80})` → `progress(0…1 | элемент, 'этап')` ведёт
  луч-сканер по строкам листа, дрон летит над лучом; `land()` — садится на верхний край листа, винты стихают,
  событие `bcc-agent:landed`; `say('одна строка')`, `stage('этап')`, `takeoff()`, `destroy()`.
  Без JS: `data-bcc-scan data-progress="0.4" data-stage="правила"`, `data-bcc-scan="land"`, `data-land="left"`.
  Один `requestAnimationFrame` на всех, рисует только видимое, `prefers-reduced-motion` — неподвижные кадры.
- **Окно ключа — запасной путь** (`/welcome`, когда терминала нет): белый лист на тёмном столе, номера строк,
  ключ — в строке 4, подсказка со ссылками на AI Studio и консоль Anthropic. Проверка: дрон взлетает и сканирует
  поле ключа, потом садится на край листа. Успех — печать «КЛЮЧ ПРИНЯТ» с маской и флажок «Запомнить (.env)».
  Ошибка — волнистое подчёркивание поля и заметка K-01 на полях (на узком экране — под полем). Провайдер — по
  началу ключа (`AIza…` — Gemini, `sk-ant-…` — Claude). «Продолжить без ключа» → система в режиме правил.
- **`POST /api/key`**: проверка — `doctor.run_doctor(live=True, …)`; 403 при чужом `Origin`; ключ не попадает
  в ответ, журнал и HTML — только маска `AIza…3f9Q`.
