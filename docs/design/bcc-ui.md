# BCC Review — дизайн интерфейса

Слова владельца (27.11.2026): «как в моём проекте Зерде: чистый дизайн, текста немного, но по факту; цвета BCC; для
глаза как мёд, всё плавно, красиво; liquid glass — уместный». Образец стиля — дизайн v2 проекта «Зерде»: Apple-like,
чисто, три слоя, мягкие тени вместо рамок, одна главная кнопка на экран. Цвета — из брендбука BCC (Visual Guidelines,
2024, стр. 37–40). Логотип и знак банка не рисуем и не копируем: у нас свой знак, от BCC — только цвета.

Этот файл обязателен для всех, кто меняет веб (`src/bcc_review/v2/web/`) и вид отчёта
(`src/bcc_review/v2/render/html_assets/`).

## 1. На экране только то, что нужно сейчас

- Один экран отвечает на один вопрос: «Что проверить?» → «Что делает агент?» → «Можно ли начинать разработку?».
- На экране не больше одной главной (зелёной) кнопки, одной строки состояния и четырёх чисел в сводке.
- Пояснения прячем под нажатие («Как это работает», «Подробнее»). На экране — заголовок и одна строка, не абзацы.
- Нельзя прятать: вердикт, блокеры, цитаты с номерами строк, предупреждения («нет ключа», «прогон неполный»,
  «цитата не сверена»). Предупреждение — одной строкой, подробности по нажатию.
- На 1440×900 главное (зона загрузки, список этапов, вердикт) видно без прокрутки.

## 2. Три слоя

| Слой | Что это | Как сделать |
| :--- | :--- | :--- |
| Фон | тихий, светлый, с двумя мягкими пятнами BCC | `--b-canvas`; зелёное пятно слева сверху `rgba(0,185,117,.18)` 680 px, золотое справа сверху `rgba(220,162,98,.26)` 620 px, `filter: blur(110px)`, `position: fixed`: пятна стоят на месте, стеклу есть что преломлять |
| Бумага | белые поверхности с данными | `background: var(--b-paper); border: 0; border-radius: var(--b-r-lg); box-shadow: 0 0 0 1px var(--b-hair), var(--b-shadow-1)`, внутри `--b-pad` |
| Стекло | только то, что плавает над данными | верхняя панель, реплика BCC AI, панель фильтров, боковое окно с документом |

Стекло: `background: linear-gradient(180deg, rgba(255,255,255,.76), rgba(255,255,255,.56));
backdrop-filter: blur(24px) saturate(175%); box-shadow: inset 0 1px 0 rgba(255,255,255,.95), 0 0 0 1px
rgba(15,40,65,.06), var(--b-shadow-2)`. Не больше трёх стеклянных поверхностей на экране. Нельзя: стекло на стекле,
стеклянные строки таблиц, блики, градиенты-«леденцы», неон. Где нет `backdrop-filter`, та же поверхность — белая на 92 %.

## 3. Цвета BCC и смысл цвета

Брендбук: BCC Green `#00B975`, BCC Gold `#DCA262` (основной цвет знака), BCC White, BCC Black. Поддержка: Light Green
`#61D894`, Soft Green `#B5F4C5`, Mild Green `#E3FFD9`, Light Gold `#F2BD7C`, Soft Gold `#FBE1BA`, Mild Gold `#FFF9D6`,
Light Grey `#F3F6F5`, Grey `#E7EDEB`. Бизнес-палитра: Dark Blue `#0F2841`, Blue `#1C446C`. Фирменный шрифт Suisse
Int'l платный, у нас Inter или системный (замена по брендбуку — Arial).

Цвет означает смысл, одинаково на всех экранах:

| Цвет | Смысл | Где |
| :--- | :--- | :--- |
| зелёный | можно, сверено, готово | вердикт «можно», «цитата сверена», этап выполнен |
| красный | только блокер или ошибка | критичное, «нельзя», ошибка прогона |
| золотой | существенное, ждём ответа | существенные замечания, вопросы владельцу |
| синий | незначительное, справка | незначительные, ссылки |
| без цвета | нейтрально | всё остальное |

Серого текста нет: основной `--b-ink`, вторичный `--b-ink-2`, `--b-ink-3` — только подписи от 15 px. Золотой и
светло-зелёный текст на белом нельзя (контраст ниже 4.5): золото — заливки и пятна, текст на них `--b-gold-ink`.
Главная кнопка — заливка `--b-green-strong` с белым текстом (контраст 4.7); чистый BCC Green `#00B975` — акценты:
галочки, полоса прогресса, луч сканера, точка «сверено», кольцо фокуса.

## 5. Размеры

- Текст 17 px, вторичный 15 px (не меньше). Заголовок страницы `clamp(34px, 3.2vw, 46px)`, вес 700,
  `letter-spacing: -.035em`; заголовок раздела 22 px; число в сводке 30 px.
- Кнопка и поле — 46 px в высоту; строка списка или таблицы — не ниже 52 px.
- Скругления: поле 14, поверхность 22, окно 28; всё, что выполняет действие, — капсула (`border-radius: 999px`).
- Между блоками `--b-gap`, внутри поверхности `--b-pad`. Контент — до 1180 px по центру; на телефоне поля 16 px,
  горизонтальной прокрутки нет.

## 6. Движение «как мёд»

- Кривая `--b-ease`; 120 мс — наведение, 220 — переходы, 360 — появление.
- Поверхности появляются один раз: прозрачность 0 → 1 и сдвиг на 8 px вверх, по очереди с шагом 40 мс.
- Наведение: подъём на 1 px и тень `--b-shadow-2`; нажатие: `scale(.98)`. Откликается всё, что нажимается.
- Числа не «крутятся», ничего не прыгает, бесконечных анимаций нет. Исключение — дыхание BCC AI (±2 px, период
  2.5 с); оно останавливается, когда вкладка скрыта.
- `prefers-reduced-motion: reduce` — никакого движения, маскот показывает статичный кадр.

## 7. BCC AI — маскот

- **Кто.** «Review Agent» — пиксельный дрон 80×80 с титульного слайда команды
  (`docs/design/source/stupits-title-slide.html`: функция `makeDrone`, палитра `DSK`, режимы `idle`, `scanning`,
  `analyzing`, `verified`, `alert`). В интерфейсе его зовут «BCC AI».
- **Где живёт.** В тёмно-синей плитке, как иконка приложения: `#0F2841` с радиальным градиентом
  `#20395A → #070B16`, радиус 28 % размера, тонкая светлая кромка `inset 0 0 0 1px rgba(255,255,255,.08)`.
  Так пиксельный персонаж спокойно сидит в чистом светлом интерфейсе. Рисуется в `canvas` с
  `image-rendering: pixelated`, размер кратен 80 px логической сетки: 160 px на знакомстве, 96 на прогрессе,
  40 в шапке.
- **Режимы.** Знакомство — `idle` (моргает, смотрит на курсор); проверка ключа — `analyzing`; ключ принят —
  `verified` (искры один раз); ошибка — `alert`. Прогон: чтение, правила, ревьюеры — `scanning`; судья и вопросы —
  `analyzing`. Итог: `verified`, если блокеров нет; если есть — `alert` на 1.5 с, затем `idle`.
- **Речь.** Реплика в стеклянном облачке рядом: одно-два коротких предложения, печатается быстро (около 10 мс на
  символ), щелчок показывает сразу. Тон дружелюбный, на «вы», без цепочек восклицаний и без эмодзи.

## 8. Экраны

1. **Знакомство** — первый запуск, когда нет ни одного провайдера с моделью. BCC AI 160 px и реплика
   «Здравствуйте! Я BCC AI, проверяю ТЗ до начала разработки. Чтобы думать, мне нужен ключ модели.» Три выбора-капсулы:
   «Ключ Gemini — бесплатно» (ссылка «получить за минуту» на https://aistudio.google.com/apikey), «Ключ Claude»,
   «Без ключа». Поле ключа скрыто точками, есть «показать»; «Проверить ключ» → «Ключ работает» → флажок «Запомнить
   на этом компьютере (файл .env)» → «Открыть систему». «Без ключа» ведёт в систему: готовые отчёты и проверка
   своего документа только правилами, с честной пометкой. Если провайдер уже есть (ключ в окружении или `.env`,
   Claude Code CLI), экран не показываем.
2. **Главная.** Заголовок «Проверка ТЗ до разработки» и одна строка; зона загрузки (бумага; перетащить или выбрать;
   PDF, Word, Markdown, TXT, HTML); строка состояния провайдера («Gemini · ключ проверен» или «Без ключа: только
   правила и готовые отчёты»); главная кнопка «Проверить»; ниже «Готовые отчёты» — 3–4 карточки, открываются сразу
   и без ключа; «Как это работает» — раскрывашка.
3. **Прогресс.** BCC AI 96 px; этапы списком: чтение → правила → нарезка → четыре ревьюера → судья → вопросы →
   отчёт. Выполненный этап — зелёная галочка, текущий — мягко пульсирующая точка; время и число вызовов модели —
   одной строкой.
4. **Отчёт.** Сверху крупно вердикт («Разработка: нельзя · Тестирование: нельзя») и полоса из четырёх чисел
   (блокеры, существенные, вопросы, «цитат сверено N из N»); дальше блокеры списком — одна поверхность, строки через
   тонкую линию; вкладки-капсулы «Замечания · Вопросы · Документ · Исправленная редакция · Выгрузки»; щелчок по
   замечанию открывает боковое стеклянное окно с документом и подсвеченными строками.

## 9. Проверка гармонии перед «Готово»

1. Левые края заголовка, сводки и списков — на одной линии; правые тоже.
2. Между блоками одно расстояние, внутри поверхностей одно.
3. Одна и та же вещь выглядит одинаково везде: критичность, цитата, номер строки, вердикт.
4. На экране не больше трёх уровней важности; нет плитки в плитке; у вложенного блока нет одновременно рамки, тени
   и своего фона.
5. 1440×900, 1366×768, 390×844 и масштаб 125 %: ничего не налезает, нет горизонтальной прокрутки.
6. Снимки соседних экранов рядом (главная, знакомство, отчёт) выглядят как один продукт.
7. Клавиатура: Tab идёт по порядку, фокус виден (`outline: 3px solid rgba(0,185,117,.55); outline-offset: 2px`);
   контраст текста не ниже 4.5.
