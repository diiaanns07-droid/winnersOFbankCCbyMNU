# Контрольный документ rb.conflict

* **КБ-6.** Возврат покупки уменьшает кэшбэк следующего начисления.
* **КБ-8.** Возврат покупки не меняет начисленный кэшбэк.

Для карты другого клиента метод возвращает 403.

| Код | Когда возвращается |
| :--- | :--- |
| 404 | Карта не найдена или не принадлежит клиенту |
