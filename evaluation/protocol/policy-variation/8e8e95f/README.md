# Повтор на сборке 8e8e95f

В передаче Max указан коммит сборки `8e8e95f4bb8a65bdd10d7e4599dd4747ffe8c803`. Повтор включает все 16 содержательных документов в каждой из трёх форм и те же восемь заранее выбранных входов для возможного живого сравнения. Исходный эталон PV-1 и критерии от 03615d6 применяются к обеим сборкам. [Передача Max](https://github.com/diiaanns07-droid/winnersOFbankCCbyMNU/blob/08d3af55446ef37d8d61d077848e63c292a47207/contracts/HANDOFF.md) · [Протокол](../README.md)

До просмотра результатов новой сборки записан дополнительный эталон PV-1.1. При разборе прежнего SHA обнаружилось, что в одной семье перефразирование добавило отдельно проверяемое ограничение. Вторичный подсчёт учитывает четыре редакционных дефекта minor в этой форме. Для остальных форм применяется PV-1. Хеш поправки и исходный состав зафиксированы в [паспорте сравнения](comparison.json).

Официальный запуск на кейсе организаторов ведёт Max через Anthropic. Закрытая восьмёрка подготовлена для отдельного сравнения с Gemini. Для нового кандидата оператор использует штатный адаптер SDK и передаёт автоматические отчёты хранителю. Бюджет закрытой панели требует отдельного согласования. [Состояние официального прогона](https://github.com/diiaanns07-droid/winnersOFbankCCbyMNU/blob/08d3af55446ef37d8d61d077848e63c292a47207/release/reports/live/README.md)
