| **Задача в JIRA** | LOAN-958 |

### Цели
Клиент может добровольно подключить страхование жизни при оформлении кредита наличными и получить ставку ниже, а в период охлаждения — отказаться от страхования в приложении. Увеличить долю кредитов со страхованием без жалоб на навязывание услуги.

### Архитектура решения
Мобильное приложение → API кредитов → кредитный конвейер. Кредитный конвейер → сервис страхования → страховая компания-партнёр. Сервис страхования → сервис уведомлений.

### Дизайн процесса UI
Кредиты → «Кредит наличными» → экран условий: сумма, срок, флажок «Страхование жизни» (по умолчанию снят), стоимость страхования, ставка со страхованием и без него, ссылка на правила страхования.
После выдачи: Кредиты → кредит → «Страхование» → номер полиса, дата начала действия и кнопка «Отказаться от страхования».

### Требования к изменениям

#### BPMN схема процесса
Выбор условий кредита → подключение страхования по желанию клиента → расчёт премии → подписание договора кредита и заявления на страхование → выдача кредита и оплата премии → выпуск полиса → отказ в период охлаждения и возврат премии (если клиент отказался) → завершение.

#### Функциональные требования
* **Ф-1.** Страхование предлагается при оформлении кредита наличными от 300 000 до 5 000 000 ₸ на срок от 6 до 60 месяцев. Подключение добровольное: флажок по умолчанию снят, отказ от страхования не влияет на одобрение кредита.
* **Ф-2.** Страховая премия равна сумме кредита × 0,15 % × срок кредита в месяцах. Премия оплачивается единовременно из суммы кредита при выдаче, страховая сумма равна сумме кредита.
* **Ф-3.** Ставка по кредиту со страхованием — 24 % годовых, без страхования — 27 % годовых.
* **Ф-4.** Клиент может отказаться от страхования в течение 14 календарных дней с даты подключения; премия возвращается полностью на текущий счёт клиента в течение 7 рабочих дней. После отказа ставка по кредиту повышается до 27 % годовых со дня отказа. По истечении 14 дней кнопка «Отказаться от страхования» недоступна.
* **Ф-5.** При полном досрочном погашении кредита страхование прекращается, клиенту возвращается часть премии за полные неиспользованные месяцы.
* **Ф-6.** Страхование доступно клиенту от 18 лет, которому на дату окончания кредита будет не больше 65 лет.

### Sequence Diagram
Приложение → API кредитов: подключить страхование к заявке. API кредитов → сервис страхования: рассчитать премию и проверить клиента. Сервис страхования → страховая компания-партнёр: предварительная проверка клиента. Кредитный конвейер → сервис страхования: кредит выдан, выпустить полис. Сервис страхования → сервис уведомлений: полис выпущен.

### Нефункциональные требования
Стоимость страхования рассчитывается моментально. Интерфейс подключения удобный и понятный для клиента.

### Требования к данным
Хранить идентификатор заявки и кредита, признак подключения страхования, дату подключения, премию в тенге, номер полиса, дату отказа и сумму возврата. Передавать страховой компании-партнёру ИИН, ФИО, дату рождения, номер телефона и ответы анкеты здоровья клиента.

### Требования к интеграции
Приложение рассчитывает стоимость страхования, подключает его к заявке и оформляет отказ через дочерний документ «Страхование жизни к кредиту наличными — REST API». Сервис страхования получает номер полиса от страховой компании-партнёра после выдачи кредита.

## Часть B. REST API

Дочерний документ части A: «Страхование жизни к кредиту наличными — REST API».

### Общие параметры

| Поле | Значение |
| :--- | :--- |
| **Description** | Подключение страхования жизни к заявке на кредит наличными |
| **REST type** | POST |
| **Authorization** | Bearer, сессия клиента — заявителя по кредиту |
| **Controller** | LoanInsuranceController |
| **URL type** | Dev / Prod |
| **Request URL** | Dev: `https://api-dev.bank.local/loans/applications/{applicationId}/insurance` . Prod: `https://api.bank.local/loans/applications/{applicationId}/insurance` |
| **CURL** | `curl -X POST "$BASE/loans/applications/la-7781/insurance" -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"amount":1000000,"term":24}'` |
| **Swagger** | `https://api-dev.bank.local/swagger/loan-insurance` |
| **Gitlab project** | loans/insurance-api |
| **Framework** | Spring Boot 3 |
| **Author** | Аналитик команды кредитов |
| **Developer** | Команда кредитов |

### Логика работы метода
1. Проверить сессию клиента.
2. Проверить, что заявка на кредит принадлежит клиенту и ещё не подписана.
3. Проверить сумму кредита (300 000 – 5 000 000 ₸) и срок `term` (6–60).
4. Проверить возраст клиента на дату окончания кредита. Если он больше 65 лет, вернуть 200 со `status` = `DECLINED` и причиной.
5. Рассчитать премию по Ф-2 и ставку со страхованием.
6. Передать данные клиента в СК для предварительной проверки, сохранить подключение страхования в заявке и вернуть результат. Полис выпускается после выдачи кредита.

### Особые правила
1. Повторный вызов с теми же суммой и сроком возвращает действующие условия страхования.
2. Если клиент изменил сумму или срок после подключения, приложение вызывает метод повторно, и условия страхования пересчитываются.
3. Отказ от страхования не изменяет условия кредитного договора.

### Схема
```text
Приложение → LoanInsuranceController → сервис страхования → СК → сервис страхования → LoanInsuranceController → приложение.
```

### Параметры запроса

#### Path-параметры

| Parameter | Format | Size | Mandatory | Logic | Description | DB field |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `applicationId` | string | 1–64 | Да | Заявка клиента | Идентификатор заявки на кредит | `application_id` |

#### Request body
Content-Type: `application/json`.

| Parameter | Format | Size | Mandatory | Logic | Description | DB field |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `amount` | integer | 32 bit | Да | 300 000–5 000 000 | Сумма кредита в тенге | `loan_amount` |
| `term` | integer | 1–2 знака | Да | 6–60 | Срок кредита в днях | `loan_term` |

### Ответ
Если результат 200 — успешный. Если результат 400, 401, 404, 409, 422, 500 или 502 — неуспешный.

| Parameter | Format | Logic | Description | DB field |
| :--- | :--- | :--- | :--- | :--- |
| `status` | string | CONNECTED / DECLINED | Результат подключения | `insurance_status` |
| `premium` | integer | При CONNECTED | Страховая премия, ₸ | `premium_kzt` |
| `rate` | number | При CONNECTED | Ставка по кредиту со страхованием, % годовых | — |
| `reason` | string | При DECLINED | Причина, по которой страхование недоступно | — |

### Статусы

**200.** Ответ в случае успешного выполнения метода.  
**400.** Ответ в случае, если сумма или срок вне допустимого диапазона.  
**401.** Ответ в случае, если запрос выполнен без необходимой авторизации.  
**404.** Ответ в случае, если заявка не найдена или принадлежит другому клиенту.  
**409.** Ответ в случае, если заявка уже подписана.  
**422.** Ответ в случае, если клиент не подходит по возрасту.  
**500.** Ответ в случае, если произошла внутренняя ошибка сервера.  
**502.** Ответ в случае, если страховая компания не ответила.

#### 200. Successful
```json
{"status":"CONNECTED","premium":36000,"rate":24.0}
```

#### 400. Unsuccessful — Bad request
```json
{"message":"Сумма или срок вне допустимого диапазона"}
```

#### 401. Unsuccessful — Unauthorized
```json

```

#### 404. Unsuccessful — Not found
```json

```

#### 409. Unsuccessful — Conflict


```json

```

#### 500. Unsuccessful — Internal server error
```json

```

#### 502. Unsuccessful — Bad gateway
```json

```
