# Результаты оценки ядра v2

Владелец: №15. Все числа считает код; отчёты агента руками не правятся. Время — Астана (UTC+5).

## Как считаем

```bash
# официальный документ: эталон К1–К5, С1–С20, М1–М8 (evaluation/v2/official/gold.yaml)
python -m evaluation.v2.score runs/<id>/report.json --run-dir runs/<id> --arbiter sonnet \
    --out evaluation/v2/measurements/<метка>/score.json --md evaluation/v2/measurements/<метка>/score.md \
    --label "<метка>" --history evaluation/v2/history.jsonl
# анти-подгонка промптов
python -m evaluation.v2.antifit
```

* **Сопоставление** замечания с эталоном детерминированное: цитаты замечания ищутся в документе, их строки
  сравниваются со строками-опорами эталона; плюс ключевые слова сути дефекта. Для противоречия нужны цитаты
  **обеих** сторон. Одно замечание засчитывается только за один пункт эталона (паросочетание, критичные первыми).
* **Спорные пары** (совпали строки, но мало ключевых слов, или цитирована одна сторона противоречия) и замечания
  **вне эталона** размечает LLM-арбитр (`claude -p --model sonnet`), решения с причинами пишутся в
  `official/arbiter_cache.jsonl` — повторный подсчёт детерминирован и бесплатен.
* **Строгий** счёт: спорное без решения арбитра не засчитывается. **Нестрогий**: засчитывается.
* **Дубль** — второе и следующие замечания на один пункт эталона. **Критичный ложный** — `critical` вне К1–К5
  (или на пункте, где критичность по эталону недопустима).
* Цитаты проверяются независимо от `verify` агента; «общие фразы» — словарь `common.GENERIC_PHRASES`;
  английские слова — латиница вне словаря документа и общепринятых сокращений (ISO, HTTP, API, …).

## Ограничения

* Эталон составлен командой (`docs/task-analysis.md`, раздел 5), а не организаторами; это наш взгляд на дефекты.
* Ключевые слова эталона — регулярные выражения по-русски; редкая формулировка может не совпасть, такие пары
  уходят арбитру. Арбитр — тоже модель (Sonnet), его решения и причины открыты в `official/arbiter_cache.jsonl`.
