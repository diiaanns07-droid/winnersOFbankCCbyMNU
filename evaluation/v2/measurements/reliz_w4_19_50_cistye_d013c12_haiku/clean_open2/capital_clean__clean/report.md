**<a id="q-01"></a>Q-01** Начисления за текущие сутки в экране и ответе API · можно ответить позже · кому: Владелец продукта · к [D-05](#d-05)

Где: Ф-2, строка 37: «Проценты начисляются ежедневно на остаток счёта на конец дня»; Часть B › Ответ, строка 160: «Проценты, начисленные за текущий месяц по Ф-2 на дату запроса»; Часть A › Дизайн процесса UI, строка 28: «проценты за текущий месяц»

- **A** Сумма включает только завершённые дни: начисления по остатку на 23:59:59 предыдущего дня по Астане (UTC+5), текущие сутки не учитываются

- **C** Сумма включает текущие сутки, но на экране выводится отдельной строкой «за сегодня» с пометкой «предварительно», а в ответе API поле `accruedInterest` считается только по завершённым дням

Что возвращать методу условий и истории начислений для закрытого счёта: код 404 или 200 с историей? В описании кодов 404 закрытый счёт указан, а в описании методов 2 и 3 — нет.  
Где: Часть B › Статусы, строка 167: «404. Ответ в случае, если счёт не найден или закрыт либо счёт или карта принадлежат…»; Часть B › Методы чтения, строка 201: «404 — счёт не найден или принадлежит другому клиенту»

- **A** Для методов 2 и 3 закрытый счёт возвращает 404, как и метод 1; в описании методов 2 и 3 добавляется «или закрыт»
- **B** Для методов 2 и 3 закрытый счёт возвращает 200 с историей начислений и условиями только для чтения; 404 только для счёта, не найденного или принадлежащего другому клиенту

Зачем: Клиент, закрывший счёт, получит разные ответы от одного и того же счёта в зависимости от того, какой метод вызывает приложение, и тест на 404 для методов чтения нельзя написать однозначно.

**Шкала серьёзности**

- 🔴 **Критичный** — два места документа дают несовместимый результат для одного входа; ключевое правило нельзя однозначно реализовать или проверить; нет информации, без которой основную функцию не реализовать.
- 🟠 **Существенный** — неоднозначность или неполнота, ведущая к неверной реализации или спору при приёмке; непокрытая ветка (ошибки, повторы, отмены, границы); риск ИБ; расхождение типов, единиц, терминов.
- 🟡 **Незначительный** — оформление, незаполненный шаблон, версия и согласования, отсутствие ID и приоритетов, стиль.

**Вердикт.** Критичный дефект, блокирующий разработку, — разработку начинать нельзя; то же для тестирования. Иначе при трёх и более существенных дефектах по направлению — «можно с условиями»: начинать части, не затронутые дефектами, и исправлять их параллельно. Иначе — «можно». Частичный прогон не даёт «можно»: в лучшем случае «с условиями».

**Сверка цитат.** Сравнение без учёта регистра, вида кавычек и тире, лишних пробелов и разметки; цитата ищется у указанной строки, затем во всём документе, ближе к требованию. Нечёткое совпадение (не ниже 92 %) допускается только рядом с указанной строкой.
