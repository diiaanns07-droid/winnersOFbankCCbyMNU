# Хабарландыру қызметіне қойылатын талаптар

## 1. Рөлдер

Клиент, оператор.

## 2. Талаптар

Ф-1. Жүйе есептен шығарылғаннан кейін 5 секунд ішінде клиентке push-хабарлама жіберуі керек.

Ф-2. Оператор жеткізу мәртебесін көруі тиіс: «жіберілді», «жеткізілді», «қате».

Ф-3. Қате болған жағдайда жүйе жіберуді 1 минут аралықпен 3 ретке дейін қайталайды.

Ф-4. Клиент профиль баптауларында хабарламаларды өшіре алады.

## 3. Интерфейстер

API POST /notify client_id, amount, currency өрістерін қабылдайды.
