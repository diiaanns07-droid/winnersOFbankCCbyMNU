35Функциональные требования
36R-05Ф-1. Льготный период действует для покупок по кредитной карте и длится до 55 календарных дней. Расчётный период равен календарному месяцу, выписка формируется 1-го числа следующего месяца, платёжный период заканчивается 25-го числа того же месяца. Если 25-е число приходится на выходной или праздничный день, окончание платёжного периода не переносится.D-08
37R-06Ф-2. Сумма для погашения без процентов равна задолженности по покупкам расчётного периода на дату выписки. Покупка относится к расчётному периоду по дате её отражения на счёте карты. Снятие наличных, переводы с кредитной карты, операции, приравненные к снятию наличных (квази-кэш), и комиссии банка в льготный период не входят: проценты по ним начисляются с даты операции.D-04D-08D-09D-10+1
38R-07Ф-3. Если клиент внёс сумму для погашения полностью до окончания платёжного периода включительно, проценты по покупкам расчётного периода не начисляются. Если внесено меньше, проценты начисляются на всю задолженность по покупкам расчётного периода с даты отражения каждой покупки на счёте.D-11D-12
39R-08Ф-4. Если переключатель «Напоминать о платеже» включён и сумма для погашения не внесена полностью, за 3 календарных дня до окончания платёжного периода клиент получает push с датой окончания и оставшейся суммой. По умолчанию переключатель включён.D-05D-09D-13D-14D-15+2
40R-09Ф-5. Платёж считается внесённым в момент зачисления на счёт кредитной карты; платёжный период заканчивается 25-го числа в 23:59:59 по времени Астаны (UTC+5). Внесённый платёж уменьшает оставшуюся сумму для погашения. Возврат покупки, отражённый до окончания платёжного периода, тоже уменьшает оставшуюся сумму; возврат, отражённый позже, уменьшает задолженность, но утраченный льготный период не восстанавливает. Покупки, отражённые на счёте после окончания расчётного периода, относятся к следующему расчётному периоду и сумму для погашения не меняют.D-08D-09D-11D-16+1
