# Проверка на новом входе

В обеих версиях банк задаёт предел операции 12 700 тенге. В `clash.md` изменена одна верхняя граница в описании метода на 24 500. Эта пара проверяет, реагирует ли конкретный путь обработки на изменение смысла. Одного примера недостаточно для оценки полноты продукта.

Результаты BCC Review получены на `9d1e157c` без модели, с параметрами `--provider mock --no-cache --no-html`. На каждом документе штатная команда выделила восемь пунктов, записала свой SHA-256 и выдала разрешение старта при нуле замечаний. Сопоставление отчёта с правильным исходником завершилось кодом 0, с подменённым — кодом 4 в обе стороны. Так подтверждаются чтение и привязка к файлу. Чувствительность к смыслу в таком режиме на этой паре отсутствует.

```powershell
$pair = 'evaluation/v2/competition_audit/common'
python -m bcc_review "$pair/clash.md" out/f4-common/clash.md --provider mock --no-cache --no-html
python -m bcc_review verify out/f4-common/clash.json "$pair/clash.md"
python -m bcc_review verify out/f4-common/clash.json "$pair/aligned.md"
```
