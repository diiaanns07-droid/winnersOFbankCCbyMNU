# Суточный лимит переводов по номеру телефона

Открытый учебный документ корпуса bcc-eval. Семейство transfer_limit.

## Часть A. Бизнес-требования

### Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Суточный лимит переводов по номеру телефона |
| **Продукт** | Мобильный банк |
| **Задача в Jira** | EVAL-404 |
| **Версия документа** | 1.0 от 01.11.2026 |

### Цели
Клиент ограничивает сумму исходящих переводов по номеру телефона за сутки.

### Термины
* **Сутки** — интервал с 00:00:00 до 23:59:59 по времени UTC+5 (Asia/Almaty).
* **Использовано** — сумма выполненных за текущие сутки переводов по номеру телефона в тенге.

### Функциональные требования
* **ЛП-1.** Клиент задаёт лимит целым числом от 10 000 до 3 000 000 ₸ включительно. Лимит по умолчанию — 1 000 000 ₸.
* **ЛП-2.** Перевод выполняется, если после него использованная сумма не превысит лимит.
* **ЛП-3.** Перевод, после которого использованная сумма превысила бы лимит, отклоняется с сообщением «Превышен суточный лимит».
* **ЛП-4.** Отменённый перевод уменьшает использованную сумму суток, в которые он был выполнен.
* **ЛП-5.** Новый лимит действует начиная со следующего перевода.
* **ЛП-6.** Приложение показывает лимит и остаток лимита на текущие сутки.

### Требования к данным
Хранить идентификатор клиента, дату суток по UTC+5, лимит в тенге и использованную сумму в тенге с точностью до тиына.

### Требования к интеграции
Приложение читает лимит и использованную сумму методом getTransferLimit и меняет лимит методом setTransferLimit. Методы описаны в части B.

### Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Лимит 100 000 ₸, использовано 60 000 ₸ | Перевести 40 000 ₸ | Перевод выполнен, остаток 0 ₸ |
| Лимит 100 000 ₸, использовано 60 000 ₸ | Перевести 40 000,01 ₸ | Перевод отклонён с сообщением «Превышен суточный лимит» |
| Использовано 100 000 ₸ при лимите 100 000 ₸ в 23:59 | Перевести 10 000 ₸ в 00:01 следующих суток | Перевод выполнен |

## Часть B. REST API

### Метод setTransferLimit

| Поле | Значение |
| :--- | :--- |
| **REST type** | PUT |
| **Request URL** | `/limits/phone-transfers` |
| **Authorization** | Bearer, сессия клиента |
| **Content-Type** | `application/json` |

#### Тело запроса

| Parameter | Format | Mandatory | Logic | Description |
| :--- | :--- | :--- | :--- | :--- |
| `limit` | integer | Да | от 10 000 до 3 000 000 включительно | Лимит в тенге |

### Статусы

| Код | Когда возвращается | Тело ответа |
| :--- | :--- | :--- |
| 200 | Запрос выполнен | Описано в разделе метода; для setTransferLimit тело пустое |
| 400 | Лимит вне диапазона от 10 000 до 3 000 000 или не целое число | `{"message":"Проверьте лимит"}` |
| 401 | Нет действующей сессии | `{"message":"Требуется вход"}` |
| 500 | Внутренняя ошибка сервиса | `{"message":"Ошибка сервиса"}` |
