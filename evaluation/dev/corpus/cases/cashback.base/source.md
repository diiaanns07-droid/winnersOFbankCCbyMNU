# Кэшбэк в выбранной категории

Открытый учебный документ корпуса bcc-eval. Семейство cashback.

## Часть A. Бизнес-требования

### Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Кэшбэк в выбранной категории |
| **Продукт** | Мобильный банк |
| **Задача в Jira** | EVAL-101 |
| **Версия документа** | 1.0 от 01.11.2026 |

### Цели
Клиент выбирает одну категорию покупок на месяц и получает кэшбэк за покупки в этой категории.

### Термины
* **Месяц** — календарный месяц по времени UTC+5 (Asia/Almaty).
* **Покупка** — операция оплаты картой, которую карточный процессинг передал со статусом «проведена».
* **Категория** — одна из категорий «Кафе» (CAFE), «Такси» (TAXI), «Аптеки» (PHARMACY).

### Функциональные требования
* **КБ-1.** Клиент выбирает категорию до конца текущего месяца. Выбор действует с первого дня следующего месяца.
* **КБ-2.** Кэшбэк начисляется за покупки в выбранной категории на сумму от 500 ₸ включительно.
* **КБ-3.** Ставка кэшбэка составляет 5 % от суммы покупки.
* **КБ-4.** Сумма кэшбэка за месяц не превышает 10 000 ₸.
* **КБ-5.** Кэшбэк за месяц зачисляется на карту 5-го числа следующего месяца.
* **КБ-6.** Возврат покупки до зачисления кэшбэка уменьшает кэшбэк месяца покупки на 5 % от суммы возврата. Возврат после зачисления уменьшает следующее зачисление на ту же величину.
* **КБ-7.** Приложение показывает выбранную категорию и кэшбэк текущего месяца.

### Нефункциональные требования
* **НФ-1.** Методы getCashback и saveCategory отвечают не дольше 500 мс для 95 % запросов при нагрузке до 50 запросов в секунду.

### Требования к данным
Хранить идентификатор карты, месяц, код категории, сумму каждой покупки в тиынах и кэшбэк месяца в тиынах. 1 ₸ = 100 тиынов, кэшбэк округляется вниз до целого тиына.

### Требования к интеграции
Приложение читает настройки методом getCashback и сохраняет категорию методом saveCategory. Оба метода описаны в части B.

### Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Категория «Такси», кэшбэк месяца 0 ₸ | Провести покупку «Такси» на 2 000 ₸ | Кэшбэк месяца 100 ₸ |
| Категория «Такси», кэшбэк месяца 0 ₸ | Провести покупку «Такси» на 500 ₸ | Кэшбэк месяца 25 ₸ |
| Категория «Такси», кэшбэк месяца 9 900 ₸ | Провести покупку «Такси» на 4 000 ₸ | Кэшбэк месяца 10 000 ₸ |
| Категория «Кафе», кэшбэк месяца 0 ₸ | Провести покупку «Такси» на 1 000 ₸ | Кэшбэк месяца 0 ₸ |

## Часть B. REST API

### Метод getCashback

| Поле | Значение |
| :--- | :--- |
| **REST type** | GET |
| **Request URL** | `/cashback/{cardId}` |
| **Authorization** | Bearer, сессия клиента — владельца карты |

#### Ответ 200

| Parameter | Format | Description |
| :--- | :--- | :--- |
| `category` | string | Код выбранной категории: CAFE, TAXI или PHARMACY |
| `accrued` | string | Кэшбэк текущего месяца в тенге с двумя знаками после точки |

Пример ответа для первого критерия приёмки: `{"category":"TAXI","accrued":"100.00"}`.

### Метод saveCategory

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **Request URL** | `/cashback/{cardId}/category` |
| **Authorization** | Bearer, сессия клиента — владельца карты |
| **Content-Type** | `application/json` |

#### Тело запроса

| Parameter | Format | Mandatory | Logic | Description |
| :--- | :--- | :--- | :--- | :--- |
| `category` | string | Да | CAFE, TAXI или PHARMACY | Код категории |

### Статусы

| Код | Когда возвращается | Тело ответа |
| :--- | :--- | :--- |
| 200 | Запрос выполнен | Описано в разделе метода |
| 400 | Код категории не из списка CAFE, TAXI, PHARMACY | `{"message":"Неизвестная категория"}` |
| 401 | Нет действующей сессии | `{"message":"Требуется вход"}` |
| 404 | Карта не найдена или не принадлежит клиенту | `{"message":"Карта не найдена"}` |
| 500 | Внутренняя ошибка сервиса | `{"message":"Ошибка сервиса"}` |
