# pdf_assets — шрифты PDF-экспорта (№14)

| Файл | Назначение |
| --- | --- |
| `NotoSans[wdth,wght].ttf` | **основной**: Noto Sans 2.015, вариативный TTF без изменений, байт в байт из google/fonts |
| `OFL.txt`, `METADATA.pb` | лицензия SIL OFL 1.1 и метаданные `ofl/notosans` того же коммита |
| `NotoSansMath-Regular.ttf` | **резервный**: Noto Sans Math 3.000, только для знаков, которых нет в Noto Sans (стрелки `→`, `≤ ≥ ≠`) |
| `OFL-NotoSansMath.txt`, `METADATA-notosansmath.pb` | лицензия и метаданные `ofl/notosansmath` того же коммита |
| `font.lock.json` | привязка: коммит google/fonts, SHA-256 всех файлов, версии, оси и используемые начертания |

Источник: google/fonts @ `5026800714d07231937d92eb4cceabf06e05d74e`,
каталоги [`ofl/notosans`](https://github.com/google/fonts/tree/5026800714d07231937d92eb4cceabf06e05d74e/ofl/notosans)

## Условия распространения (сверено с `OFL.txt` / `OFL-NotoSansMath.txt`)

* Строки copyright не объявляют Reserved Font Name, поэтому производные экземпляры можно
  называть исходным именем.
* OFL разрешает встраивать шрифты в программное обеспечение и распространять вместе с ним
  (п. 1–2), если шрифт не продаётся отдельно и текст лицензии лежит рядом (п. 2). Оба файла
  лицензии лежат в этом каталоге.
* Документы, созданные с помощью шрифта, под действие OFL не подпадают (преамбула). PDF-отчёты
  можно распространять без ограничений.
* Во время работы `pdf.py` строит из вариативного файла статические экземпляры Regular
  (`wght=400`) и Bold (`wght=700`) и подмножества глифов для встраивания. Это модифицированные
  версии в смысле OFL. Они остаются только внутри создаваемых PDF и под той же лицензией. Файлы
  в репозитории не меняются.
* Тексты двух лицензий отличаются только адресом сайта OFL в шапке (scripts.sil.org и
  openfontlicense.org).

`pdf.py` при загрузке сверяет SHA-256 шрифтов с `font.lock.json`. Тест
`tests/p14/test_p14_font_assets.py` проверяет хеши, лицензии, наличие ₸, кириллицы и казахских
букв, а также то, что резервный шрифт закрывает стрелки.

## Чего нет ни в одном шрифте

`✗ ☐ ☑` и CJK. Экспорт пишет предупреждение с кодами U+…, а `strict_glyphs=True` завершается
`MissingGlyphError`. Значки серьёзности в подписях рисуются векторными фигурами, а не глифами.
В тексте заметок серьёзность дублируется словом и маркером `[!!!]` / `[!!]` / `[!]`.

## Упаковка

`pyproject.toml` (зона Max) сейчас не включает `*.ttf` и `*.pb` в package-data. Для установки
не в режиме editable нужна строка:

```toml
[tool.setuptools.package-data]
"bcc_review.exports" = ["pdf_assets/*"]
```
