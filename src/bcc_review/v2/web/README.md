# Веб-демо v2 (№14)

Загрузил ТЗ → видишь этапы → получаешь интерактивный отчёт: клик по дефекту подсвечивает место в документе.

```bash
python -m bcc_review.v2.web
```

Откройте <http://127.0.0.1:8014/>. Ключи читаются из окружения и файла `.env` в текущем каталоге
(`GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_BASE_URL`); в облачной сессии Claude Code ключ не нужен —
провайдер «Claude через Claude Code CLI».

| Флаг | Что делает |
| :--- | :--- |
| `--port 8014`, `--host 127.0.0.1` | адрес сервера |
| `--provider auto` | провайдер, выбранный в форме по умолчанию |
| `--data-dir .bcc_web` | где хранить загрузки и отчёты (внутри свой `.gitignore`) |
| `--sample ФАЙЛ` | файл для кнопки «Проверить пример» (по умолчанию `release/input/requirements.md`) |
| `--pipeline-args "--engine v1"` | дополнительные флаги для `python -m bcc_review` (план Б) |
| `--fixture report.json` | показ без модели и без pipeline: этапы идут по таймеру, отчёт — из готового JSON |
| `--open` | открыть браузер |

## Что умеет

* загрузка PDF, DOCX, MD, TXT, HTML (до 20 МБ), перетаскиванием или кнопкой;
* выбор провайдера с проверкой: недоступный подписан, а при запуске без ключа — сообщение, что сделать
  (и подсказка, что «Демо без модели» работает всегда);
* прогресс по этапам: чтение, правила, нарезка, ревьюеры параллельно, судья, вопросы, отчёт;
* готовый HTML-отчёт прямо на странице и выгрузки, которые реально записал агент: HTML, Markdown, JSON,
  Word, PDF, Jira CSV, исправленное ТЗ;
* режим уточнения: во вкладке «Вопросы» отчёта отметить варианты → «Скачать ответы» → «Загрузить ответы ↻» —
  тот же документ проверяется заново с `--answers --revise`: вердикт «до и после», исправленное ТЗ.

## Как устроено

Своей логики качества у веба нет: каждая проверка — отдельный процесс
`python -m bcc_review ВХОД out/report.md --provider … --export html,json,docx,pdf,jira --runs-dir …`, ровно
как в README. Прогресс веб читает из каталога прогона (`runs/<id>/stages/*.json`, `trace.jsonl`).
Одновременно идёт не больше `--workers` проверок (по умолчанию одна: модель дорогая).
Хранилище: `<data-dir>/jobs/<id>/` — `job.json`, `input/`, `out/`, `runs/`, `run.log`.
