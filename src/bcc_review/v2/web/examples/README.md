# Готовые отчёты и примеры документов для главной (№43)

`examples.json` — что показывает блок «Готовые отчёты» на главной веб-демо (`v2/web/gallery.py`):

- `reports` — готовые отчёты агента. Каждая запись: `json`, `html`, `md` (пути от корня репозитория) и `source` —
  исходный документ. Запись, у которой нет `json`, `html` или `source`, на главной просто не показывается
  (например, `reports/requirements.*` появятся в `bcc/v2` после прогона №36). Модель, дата, вердикт и число
  блокеров берутся из самого `report.json`, руками ничего не пишем.
- `documents` — примеры для «Проверить этот документ» одним нажатием. С ключом модели проверка идёт тем
  провайдером, который выбрал бы «Автовыбор»; без ключа — `no_key` (`mock` для официального ТЗ: записанные ответы
  живого прогона; `offline` для остальных: только правила, с пометкой об этом в отчёте).

При открытии главной готовые отчёты кладутся в хранилище заданий веба (`<data-dir>/jobs/00000000-000043-…`) и
открываются тем же экраном отчёта, что и обычная проверка, без ключа и без сети. Изменился отчёт — меняется и
номер задания, старое задание удаляется само.

## `mock/` — «Демо без модели»

Отчёт официального ТЗ провайдером `mock`. Сгенерирован инструментом, **руками не править**. Пересобрать (из корня
репозитория, на чистом дереве, чтобы в паспорте отчёта не было «dirty»):

```bash
PYTHONPATH=src python -m bcc_review release/input/requirements.md src/bcc_review/v2/web/examples/mock/requirements.md --provider mock
```

## Откуда примеры документов

| Пример | Файл | Почему он |
| :--- | :--- | :--- |
| Официальный ТЗ | `release/input/requirements.md` | вход официального прогона, без ключа — `mock` |
| Тот же ТЗ в PDF | `release/input/requirements.pdf` | тот же текст в PDF (см. `release/input/PROVENANCE.md`), без ключа — `mock` |
| Другая тема: кэшбэк | `evaluation/dev/corpus/cases/cashback.base/source.md` | открытый корпус, другая предметная область |
| Чистый ТЗ (лимит переводов) | `evaluation/dev/corpus/cases/transfer_limit.base/source.md` | `evaluation/v2/RESULTS.md`, «корпус: базы и перефразы»: 0 critical, вердикт «можно / можно», P1 не нарушен |

Слепой набор (`eval/blind4`, `*.key.json`) не используется.
