# Демо «до / после»: официальный документ, ответы владельца, исправленное ТЗ

Артефакты сгенерированы агентом (руками не правились) на коммите `208f88f`, модель `claude-sonnet-5-5`
через `claude -p`. Ответы владельца — [`../answers.md`](../answers.md).

## Команды

Одной строкой — отчёт с вопросами, пересмотр по ответам, «до / после» и исправленная редакция:

```bash
python -m bcc_review release/input/requirements.md examples/v2/demo_answers/requirements.md --provider claude_cli --model sonnet --answers examples/v2/answers.md --revise
```

Повторная проверка исправленной редакции тем же агентом:

```bash
python -m bcc_review examples/v2/demo_answers/requirements.revised.md examples/v2/demo_answers/requirements.revised.review.md --provider claude_cli --model sonnet
```
